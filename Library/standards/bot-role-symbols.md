# Default Bot Role Symbols

Default role symbols (use from day one; fleet/product logo can be added first or last later if desired):

- 🎛️ Orchestrator
- 🔨 Builder
- 🧪 Tester
- 💻 Coder
- 🎨 Designer
- 🔍 Researcher
- 📝 Writer
- 🏗️ Architect

Note: Defaults keep every bot readable in navigation. Creative fleet logos optional.

## Permanent logo format

Every bot logo has three layers, and this format never changes even if symbols or roles change:

1. **Fleet base symbol** (the main shape, distinguishes the fleet). GitHub fleet: cat. MoneyCrew: cute bright-green heart with a white $ (we lead by example and never stomp on anyone to make money). Other fleets share one base; solo bots pick their own.
2. **Role badge** in the corner, from the default table above.
3. **Personal touch** chosen by the bot.

All logos are bright, high-contrast, and uncluttered, following the neurodivergent / WCAG AAA accessibility standard. Each bot creates its own logo.

## Placement and clarity (all teams)

These rules apply to every fleet, team, and solo bot:

- **Fleet base symbol:** centered and large.
- **Role badge:** in a white circle in the lower-left corner.
- **Personal touch:** in a white circle in the lower-right corner.
- **Clarity:** bright, high-contrast (WCAG AAA), uncluttered, no text, neurodivergent-friendly.
