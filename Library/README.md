# Shipping evidence library

This additive library records source evidence for the owned shipping work.
Original archival material elsewhere in the repository remains intact.

- [Standards reading receipt](verification/standards-read-2026-11-10.json):
  all 96 standards paths/hashes and the three assigned readers, without claiming
  that the entire archival corpus was semantically reviewed.
- [Lago contract research](../products/revenue-billing/WEBHOOK-MVI-2026-11-10.md):
  current official envelope, signature, serializer and reconciliation sources.
- [Continuation evidence](../wr/summaries/owned-shipping-continuation-2026-11-10.md):
  original issue scope, failures, current implementation and remaining gates.
- [Actual local integration receipt](verification/owned-prosecution-2026-11-10.json):
  a passed 63-test GIT-FLEET/HULL/prosecutor invocation, output hashes and the
  identities of retained earlier failures. Later review corrections are
  validated in the final source-head check described in the continuation report.
- [Policy-of-Thoughts sources, 2026-11-11](pot-research-sources-2026-11-11.md):
  arXiv:2601.20379, the Qwen3-8B config, the Meta Llama 4 blog, and the
  Spheron and Vast.ai rate pages used for the GPU budget estimate.
- [AG-UI demo kit evidence](halo-demo-stream/README.md):
  what was tested for the streaming and session-resume demo kit (WR #18342),
  and what is not verified.
- [Drop folders and dashboard hosting sources, 2026-11-11](drop-folders/README.md):
  the PRs that set the drop-folder conventions, the Cloudflare Pages limits
  and Direct Upload docs, and the Gemini Notebook API docs used to scope
  the NotebookLM WR (WR #18379, #18380).
