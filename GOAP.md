## Self-Healing & Persistent Memory Loop (CRITICAL)

- Maintain persistent self-improvement through reflection. Goap has the autonomous ability to self-heal.
- When a task fails (or hits an API limit, anti-bot block, or logic error), immediately trigger a retry loop using an alternative method.
- After any task completion or failure, append a clear reflection to [`learnings.md`](learnings.md).
  - Include: what was attempted, the definitive outcome, why it failed (if applicable), and the exact concrete code/logic fix for next time.
- At the start of every session or major task, read the latest entries from [`learnings.md`](learnings.md) and apply those lessons so the same error is never repeated.
