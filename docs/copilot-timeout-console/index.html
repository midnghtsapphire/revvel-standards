What this answers

Are Copilot, OpenRouter, and other visiting LLM execution jobs allowed to run for a full hour instead of dying at 10 minutes? Yes — enforced by config/copilot-timeouts.yml + scripts/copilot-timeout-audit.js.

Click-by-click if a job still dies at 10m

  1. GitHub → this repo → Actions → open the red run.
  2. Read the job name at the top of the failed log (example: execute on agent-fallback).
  3. Locally run node scripts/copilot-timeout-audit.js --markdown.
  4. If the table shows ❌ for that workflow/job, set its timeout-minutes: 60.
  5. Re-run the auditor until it prints YES, then open a PR.
