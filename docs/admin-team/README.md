## Purpose

Business admin, email, grants, settings, projects and outreach.

## Routing

MailClerk drafts email; FreedomAngelOps and CAGECodeClerk handle entity/registration (secrets via Secret/Proofy); GrantHunter reports matches to Proofy; SettingsSteward audits paid-app settings; Projects Manager runs Notion projects; Outbound Prospecting drafts outreach. Money/secrets escalate to Proofy.
