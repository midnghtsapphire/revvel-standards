# $10M in 3 Years Roadmap

## Prime Directive
Start at $10k/month → Scale to $10M total by year 3.

## Phase Breakdown

| Phase | Timeline | Target | Focus |
|-------|----------|--------|-------|
| 1 | Month 1-6 | $10k/month | Polar.sh setup, first OSINT tool launch |
| 2 | Month 6-18 | $30k/month | Product pipeline automation, recurring revenue |
| 3 | Month 18-30 | $100k/month | Scale distribution, enterprise tier |
| 4 | Month 30-36 | $10M total | Exit-ready SaaS portfolio |

## Focus Areas

### 1. Polar.sh — GitHub Funding
- Configure Polar org + tiers ($5, $25, $100, $500)
- Wire donation CTAs into README badges
- Track MRR weekly

### 2. OSINT Tools
- Ship one paid OSINT utility per month
- Free tier → paid tier funnel via Polar
- Distribute via HN, Reddit r/OSINT, X

### 3. Automated Product Pipeline
- Issue → PR → deploy loop (this bot)
- Landing page auto-gen per product
- Stripe/Polar checkout on every repo

## KPIs
- Weekly: new paying customers, MRR delta
- Monthly: churn %, LTV, CAC
- Quarterly: revenue vs phase target
