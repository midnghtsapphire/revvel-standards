# Prime Directive: $10k/month → $10M in 3 Years

## Mission
Scale from **$10k/month** in Month 1 to **$10M total revenue** by Month 36.

## Phases

| Phase | Timeline | Target | Focus |
|-------|----------|--------|-------|
| 1 | Month 1–6 | $10k/month MRR | Launch Polar.sh funding, ship first OSINT tool |
| 2 | Month 6–18 | $30k/month MRR | Automated product pipeline, paid tiers |
| 3 | Month 18–30 | $100k/month MRR | Enterprise OSINT, team/API plans |
| 4 | Month 30–36 | $10M total | Scale, partnerships, exit-ready |

## Focus Areas

### 1. Polar.sh — GitHub-native funding
- Enable sponsors, tiers, subscription products.
- Convert GitHub stars & issues into paid supporters.
- Publish public revenue dashboard for social proof.

### 2. OSINT Tools
- Free tier: recon CLI, limited queries.
- Pro tier ($29/mo): API access, higher limits.
- Team tier ($199/mo): shared workspace, exports.
- Enterprise: custom pricing, SLA.

### 3. Automated Product Pipeline
- Issue → PR → deploy loop (OpenRouter + OpenHands fallback).
- Auto-generated marketing pages per feature.
- Weekly release cadence, changelog → newsletter → conversions.

## KPIs (tracked monthly)
- MRR ($)
- Paying customers (#)
- Polar.sh sponsors (#)
- OSINT tool DAU/MAU
- PR merge throughput (auto-pipeline health)

## Non-Goals
- Feature creep unrelated to revenue.
- Manual work that can be automated within 1 week.
