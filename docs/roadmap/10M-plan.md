# $10M in 3 Years Roadmap

## Prime Directive
Start at $10k/month → Scale to $10M total by year 3

## Phased Milestones

| Phase | Timeline | Target MRR | Cumulative Focus |
|-------|----------|------------|------------------|
| 1 | Month 1-6 | $10k/mo | Polar.sh funding, OSINT MVP |
| 2 | Month 6-18 | $30k/mo | Product pipeline automation |
| 3 | Month 18-30 | $100k/mo | Enterprise OSINT tier |
| 4 | Month 30-36 | $10M total | Multi-product platform |

## Focus Areas

### 1. Polar.sh (GitHub Funding)
- Set up Polar.sh account and link repositories
- Publish sponsor tiers ($5, $25, $100, $500)
- Automate release notes → sponsor announcements

### 2. OSINT Tools
- Free tier: basic domain / IP / breach lookup
- Paid tier: bulk scanning, API access, reports
- Enterprise: SLA, private feeds, custom dashboards

### 3. Automated Product Pipeline
- Issue → agent (OpenRouter → OpenHands → manual)
- CI publishes artifacts, docs, and changelog
- Revenue telemetry feeds back into roadmap prioritization

## Fallback Chain
OpenRouter → OpenHands → manual (all free-tier where possible)
