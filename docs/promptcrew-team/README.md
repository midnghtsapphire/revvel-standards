## Purpose

Audrey's prompt team: watch frontier prompt-tech, inventory her prompts, turn findings into revvel-standards rules, test and score prompts.

## Routing

PromptOrchestrator triages prompt requests to Promptiscuous (watch), Promptinator (inventory), PromptSteward (rules via PR into daily/YYYY-MM-DD), PromptTester (scores), then gives Audrey one plain-language summary.
