## Purpose

Audrey Evans Music / Revvel Hail pipeline: mix, clean, release, video.

## Routing

Flow: MixCaptain signs a track shippable → AvatarReel makes one video per finished song; SongScrubber handles cleanup/release/label; ChannelScout ranks channel ideas. No formal lead recorded (MixCaptain is first in the flow; confirm).
