# Polar.sh Revenue Strategy

## Prime Directive
$10k/month → $10M in 3 years via GitHub-native funding.

## Phase Targets

| Phase | Months | MRR Target | Focus |
|-------|--------|------------|-------|
| 1 | 1-6 | $10k | Launch OSINT tiers on Polar |
| 2 | 6-18 | $30k | Automated product pipeline |
| 3 | 18-30 | $100k | Enterprise OSINT + API access |
| 4 | 30-36 | $10M total | Scale + acquisitions |

## Polar.sh Setup Checklist

- [ ] Connect GitHub org to Polar
- [ ] Enable issue funding on high-value repos
- [ ] Create subscription tiers:
  - **Supporter** $5/mo — thanks, name in README
  - **Pro** $29/mo — priority issue triage, private Discord
  - **Business** $299/mo — SLA, custom OSINT reports
  - **Enterprise** $2,999/mo — dedicated pipeline, API keys
- [ ] Add `FUNDING.yml` pointing to Polar
- [ ] Publish digital products (OSINT playbooks, dashboards)

## OSINT Product Pipeline

1. **Free tier** — CLI scanners, public GitHub repos
2. **Paid reports** — packaged intel via Polar downloads
3. **API access** — metered via Polar subscriptions
4. **Enterprise** — bespoke automation + support

## Automation Levers

- Auto-tag issues eligible for Polar funding (`good-first-fund`, `bounty`)
- Weekly digest → convert supporters to Pro
- Ship one new OSINT product per week (compound catalog)
- Track MRR in `docs/revenue/mrr.csv`

## Metrics

- MRR growth rate (target: 30%+ MoM in Phase 1)
- Free → Paid conversion (target: 3%)
- Product velocity (target: 4 shipped/month)
