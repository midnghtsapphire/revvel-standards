# Revenue Roadmap: $10k/mo → $10M in 3 Years

## Prime Directive
Scale from $10k/month baseline to $10M cumulative revenue within 36 months.

## Phase Breakdown

| Phase | Months | MRR Target | Focus |
|-------|--------|-----------|-------|
| 1 | 1-6   | $10k      | Polar.sh setup, OSINT MVP, initial customers |
| 2 | 6-18  | $30k      | Product pipeline automation, content marketing |
| 3 | 18-30 | $100k     | Enterprise OSINT tier, API monetization |
| 4 | 30-36 | $10M total| Scale, retention, upsell |

## Focus Areas

### 1. Polar.sh (GitHub Funding)
- Enable Polar.sh on all public repos
- Tiered sponsorships: $10 / $50 / $500 / $5000 monthly
- Sponsor-only Discord + priority issue triage

### 2. OSINT Tooling
- CLI + hosted API for public-record enrichment
- Free tier (rate-limited) → Pro ($29/mo) → Team ($299/mo) → Enterprise (custom)
- Ship one new module per sprint

### 3. Automated Product Pipeline
- Issue-driven agent (OpenRouter → OpenHands → manual) generates PRs
- Weekly release cadence
- Track cost-per-PR and revenue-per-repo

## KPIs
- MRR, churn, CAC, LTV
- PRs merged / week
- Cost per automated PR (target < $0.10)
