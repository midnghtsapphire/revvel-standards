## Focus Areas

### 1. Polar.sh — GitHub Funding Platform
- Enable Polar checkout on all public repos
- Tier structure:
  - $9/mo — Supporter (name in README)
  - $29/mo — Pro (private Discord, priority issues)
  - $99/mo — Team (5 seats, SLA)
  - $499/mo — Enterprise (custom integrations)
- Convert GitHub Sponsors traffic → Polar (better fees, better UX)
- Automate release-gated content: paying supporters get pre-release binaries

### 2. OSINT Tools
- Package existing recon utilities as paid CLI + SaaS
- Freemium: 10 lookups/day free, unlimited $29/mo
- Data enrichment tier: $99/mo (bulk API)
- Target: bug bounty hunters, red teams, journalists

### 3. Automated Product Pipeline
- Ship 1 micro-product per week via CI
- Each product: landing page + Polar checkout + docs
- Track conversion in `metrics/` — kill losers, double down on winners

## Weekly KPIs
- New Polar subscribers: ≥ 20/week (Phase 1)
- Churn: < 5%/month
- LTV:CAC ratio: > 3:1
- Product ship velocity: 1/week
