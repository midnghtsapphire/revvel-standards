## Polar.sh Tier Structure

### Free — $0
- Access to open-source OSINT CLI
- Community Discord
- Public issue tracker

### Supporter — $10/mo
- Sponsor badge
- Early access to new tools
- Monthly build digest

### Pro — $49/mo
- Private API keys (rate-limited)
- Priority issue triage
- Access to premium OSINT modules

### Team — $199/mo
- 5 seats
- Webhook integrations
- SLA-backed uptime for hosted endpoints

### Enterprise — Custom ($2k+/mo)
- On-prem deployment
- Custom OSINT collectors
- Dedicated support engineer

To hit **$100k/mo** in Phase 3:
