## Automation Pipeline

1. **Ingest** — GitHub issues, RSS feeds, HN, public breach dumps
2. **Enrich** — LLM summarization via OpenRouter (free tier → paid)
3. **Package** — Auto-generated Markdown reports
4. **Publish** — Push to Polar as digital downloads + gated feed
5. **Notify** — Email/Discord to subscribers
