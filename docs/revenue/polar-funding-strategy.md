# Polar.sh Funding Strategy — Path to $10M

## Prime Directive
Start at **$10k/month** → Scale to **$10M total** by year 3.

## Phase Roadmap

| Phase | Timeline | Monthly Target | Key Levers |
|-------|----------|----------------|------------|
| 1 | Month 1-6 | $10k | Polar.sh setup, GitHub sponsors, OSINT MVP |
| 2 | Month 6-18 | $30k | Product pipeline, tier upgrades, B2B outreach |
| 3 | Month 18-30 | $100k | Enterprise contracts, SaaS conversion |
| 4 | Month 30-36 | $10M total | Retention, upsell, acquisitions |

## Polar.sh Setup Checklist

- [ ] Connect GitHub org to Polar.sh
- [ ] Enable issue funding on all public repos
- [ ] Define subscription tiers ($5, $25, $100, $500/mo)
- [ ] Add Polar badge to top 10 repo READMEs
- [ ] Publish 3 paid product listings (OSINT toolkit, automation kit, reports)
- [ ] Configure webhooks → internal revenue tracker

## Subscription Tiers

### Supporter — $5/mo
- Name in CONTRIBUTORS
- Discord role

### Pro — $25/mo
- Access to private OSINT dashboards
- Monthly threat brief

### Team — $100/mo
- 5 seats
- Priority issue triage
- API access

### Enterprise — $500/mo
- Unlimited seats
- SLA, custom integrations
- Direct Slack channel

## OSINT Product Pipeline

1. **Recon CLI** — domain/subdomain/email harvesting
2. **Breach Monitor** — dark web + paste site alerts
3. **Threat Feed API** — curated IOCs, JSON/STIX
4. **Weekly Intel Report** — paid newsletter

## KPIs

- MRR growth ≥ 20% MoM in Phase 1
- Free → paid conversion ≥ 3%
- Churn ≤ 5% monthly
- CAC payback ≤ 3 months

## Automation

All product launches, README badges, and pricing sync flow through the
agent pipeline (OpenRouter → OpenHands → manual fallback) so revenue
experiments ship without human bottlenecks.
