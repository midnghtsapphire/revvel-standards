## Focus Areas

### 1. Polar.sh — GitHub Funding Platform
- Set up Polar org and connect all monetizable repos.
- Offer tiered sponsorships: $5, $25, $100, $500, $2k/mo.
- Ship paid GitHub Issue funding (bounty model).
- Convert stars → sponsors via automated outreach.
- Publish sponsor-only releases and priority support SLA.

### 2. OSINT Tools
- Package OSINT scripts as paid Polar products.
- Free tier: rate-limited CLI.
- Pro tier ($29/mo): API access, higher limits.
- Team tier ($199/mo): seats, exports, dashboards.

### 3. Automated Product Pipeline
- Every merged agent PR → candidate product.
- Nightly job: score repos by stars/traffic, promote top 3 to Polar.
- Auto-generate landing pages + pricing from repo README.
