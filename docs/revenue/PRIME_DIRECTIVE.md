# Prime Directive: $10k → $10M in 3 Years

## Mission Statement

Start at $10k/month recurring revenue. Scale to $10M total by end of year 3.

## Phase Roadmap

| Phase | Timeline | Target MRR | Cumulative | Focus |
|-------|----------|-----------|------------|-------|
| 1 | Month 1-6 | $10k/mo | $60k | Polar.sh funding + OSINT MVP |
| 2 | Month 6-18 | $30k/mo | $420k | Product pipeline automation |
| 3 | Month 18-30 | $100k/mo | $1.62M | Enterprise OSINT tier |
| 4 | Month 30-36 | $250k/mo+ | $10M | Scale + exit optionality |

## Focus Areas

1. **Polar.sh** — GitHub-native funding, subscriptions, one-time sponsorships
2. **OSINT Tools** — automated intelligence gathering, sold as SaaS + on-prem
3. **Automated Product Pipeline** — AI agents ship features while owner sleeps

## Non-Negotiables

- No scaffolding. Every merged line must move revenue or reduce cost.
- No placeholders. If it echoes "agent logic would go here" it doesn't ship.
- Automation-first. Manual toil is a bug.
- Visibility. Every workflow reports outcome; no silent failures.

## Anti-Patterns (kill on sight)

- Workflows that dispatch inputs the callee ignores (see conflict-helper Jules bug)
- Sticky comments that never update after later phases run
- Stub agents that open empty PRs
- Labels applied without corresponding user-facing status

## Metrics

Tracked weekly:
- MRR (Polar.sh dashboard)
- Active OSINT tenants
- Agent PR merge rate (auto-resolved / total conflicted)
- Owner-hours spent on toil (target: → 0)
