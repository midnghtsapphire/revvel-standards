## Required Registrations

### 1. SAM.gov (System for Award Management)

**What it does:** 
- Federal contractor registration
- Required for federal grants AND contracts
- CAGE code assignment

**CAGE Code:**
- 5-character identifier
- Required for government contracts
- **RENEW EVERY 5 YEARS**
- Freedom Angel Corp: **90SN0** (EXPIRED 2026-05-14)
- XI Website Solutions: **8ZRW3** (EXPIRED 2026-05-05)

**DLA CAGE Renewal Contact:**
- Phone: **1-877-352-2255** (1-877-DLA-CALL, 24/7)
- Email: **<dlacontactcenter@dla.mil>**
- Portal: <https://cage.dla.mil>
- Renew at: <https://sam.gov>

**Action:**
- [ ] Log into sam.gov
- [ ] Verify CAGE code status
- [ ] Submit renewal for both CAGE codes
- [ ] Update entity information

### 2. UEI (Unique Entity ID)

**What it is:** 
- 12-character unique ID
- Replaced DUNS in 2022
- Required for grants.gov

**How to get:**
1. Go to sam.gov/entity
2. Create account
3. Register entity
4. Get UEI instantly (free)

**Action:**
- [ ] Register at sam.gov/entity
- [ ] Get UEI: _____________
- [ ] Save confirmation

### 3. Grants.gov

**What it does:**
- Central portal for federal grants
- 26 federal grant-making agencies
- 1,000+ grant programs

**Registration:**
- [ ] Create grants.gov account
- [ ] Add UEI
- [ ] Subscribe to alerts
