## Template Notes (Delete Before Sending)

- Keep report concise but complete
- Use bullet points over paragraphs
- Highlight wins AND problems equally
- Always include 3 solution options for each blocker
- Update metrics with actual numbers, not placeholders
- Bold anything that needs immediate attention
- Use emojis sparingly but effectively (🟢🟡🔴 for status)
- Proactivity is key: suggest solutions, don't just report problems
- End on a forward-looking note: what's next and why it matters
