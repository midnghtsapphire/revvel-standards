## Creating New Examples

When you solve a problem autonomously:

1. **Document the problem** — full error message, context, what triggered it
2. **Explain root cause** — why did it fail, what was the actual issue
3. **Show the solution** — what you changed, why it works
4. **Describe prevention** — how to keep it from happening again
5. **Add links** — PRs, issues, documentation, tools used
