## Summary

One-line lint fix: the WR-4483 pipeline code fence gains a `text` language tag to satisfy markdownlint MD040 (fenced code blocks should have a language specified). No content changes.

Part of the per-WR lint cleanup series (1/4). One WR per PR.

[MD040 - Fenced code blocks should have a language specified](https://github.com/DavidAnson/markdownlint/blob/main/doc/md040.md)


## Rationale

- Silences MD040 in CI markdown lint step.
- `text` is the correct neutral tag for non-code prose diagrams / pipeline sketches.
- Keeps diffs minimal and reviewable — one WR per PR.

- No content edits inside the fence.
