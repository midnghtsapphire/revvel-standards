## 2. Blue Ocean Features — What Makes Neurooz Unique

### Tier 1: Core Differentiators (Launch)

#### 2.1 Oz Engine — Cognitive Mode Adaptation
**What:** AI system that detects and adapts to the user's current cognitive state in real-time.

**How it works:**
1. **Input signals:** Time of day, calendar context, recent task types, typing speed, app switching frequency, optional biometrics (Apple Watch HR in v2)
2. **Mode classification:** Focus (deep work), Creative (brainstorming), Executive Function (planning/organizing), Rest (recovery)
3. **UI adaptation:** Each mode triggers different layouts, information density, color temperature, animation levels, and notification thresholds
4. **Learning:** After 14 days, on-device ML model personalizes detection to individual patterns

**Why it's blue ocean:** No productivity app adapts its entire interface based on real-time cognitive state. Tiimo shows a schedule, Goblin Tools breaks down tasks — but neither knows WHEN you're most capable of executing those tasks.

#### 2.2 Financial Guardian with Impulse Prevention
**What:** Plaid-integrated financial monitoring that specifically targets ADHD impulse spending patterns.

**How it works:**
1. **Pattern detection:** Algorithm learns the user's impulse spending signatures (time of day, category, amount, emotional triggers)
2. **Real-time alerts:** When a transaction matches impulse patterns, sends a compassionate alert: "Hey, we noticed a purchase at [store]. This is in your impulse zone. Want to set a 24-hour cooling-off reminder?"
3. **Cooling-off periods:** User can set mandatory wait periods for specific spending categories
4. **"Emerald City" goals:** Savings goals visualized as building the Emerald City — each saved impulse purchase adds bricks
5. **Financial stress correlation:** Dashboard shows how financial stress episodes correlate with cognitive mode dips

**Why it's blue ocean:** YNAB and Mint track spending after it happens. No app prevents impulse purchases in real-time with ADHD-compassionate language. The stress-cognition correlation view is completely novel.

#### 2.3 Scarecrow AI Agent — Contextual Task Intelligence
**What:** An AI assistant with the "Scarecrow" persona that doesn't just manage tasks — it understands the intersection of work, personal, and financial obligations.

**How it works (SHIFT standard):**
1. **Memory:** Remembers past-due bills, upcoming deadlines, recent cognitive mode patterns
2. **Reflection:** Recognizes when work hyperfocus is causing personal obligations to be neglected
3. **Planning:** Creates schedules that account for ADHD energy patterns, not just time
4. **Action:** Sends alerts to preferred channels (push, Discord, Google Notes)
5. **Graceful failure:** When finances are strained, suggests "Emerald City strategies" (call provider for extension) instead of just reporting "insufficient funds"

**Why it's blue ocean:** No ADHD app has an AI agent that cross-references financial data with task management and cognitive state. The Scarecrow is the first "whole-life awareness" AI for ADHD.

### Tier 2: Advanced Differentiators (v2 — Q3 2026)

#### 2.4 Biometric Focus Detection (Apple Watch / Wearables)
**Technology:** Apple HealthKit / Google Health Connect integration

**What:** Use heart rate variability (HRV), activity level, and sleep data to enhance cognitive mode detection.
- High HRV + low heart rate → Focus mode confirmed
- Low HRV + elevated heart rate → Stress detected → suggest break
- Poor sleep night → reduce task load suggestions, shorter Pomodoro cycles
- Activity spike (exercise) → post-workout creative mode suggestion

**Cutting edge:** Combine HRV with app usage patterns for a "cognitive readiness score" — a number that tells users how ready they are for demanding tasks RIGHT NOW.

#### 2.5 Haptic Focus Cues
**Technology:** Apple Watch Taptic Engine / Android vibration API

**What:** Subtle haptic patterns that keep ADHD users on track without visual distractions:
- Gentle pulse every 5 minutes during focus sessions ("You're still on track")
- Distinct pattern when a task's Pomodoro timer ends
- Alert pattern when impulse spending detected
- Calming vibration sequence during mode transitions

**Why it's blue ocean:** Haptic feedback for ADHD focus support is unexplored territory. Current apps rely entirely on visual/audio notifications, which can break flow state.

#### 2.6 AI Body Doubling — Virtual Accountability
**Technology:** WebRTC + AI-generated ambient presence

**What:** For users who work better with someone "present," create a virtual body doubling experience:
- AI-generated ambient "study buddy" presence (audio/visual cues of someone working alongside)
- Optional real-time connection with other Neurooz users for silent co-working
- Scarecrow check-ins every 15-30 minutes: "How's it going? Still working on [task]?"
- Commitment contracts: "I'll finish [task] by [time]" with accountability follow-up

**Why it's blue ocean:** Focusmate uses real humans (scheduling friction, social anxiety). Neurooz offers instant AI body doubling — available 24/7, no scheduling, no social pressure.

#### 2.7 Spatial Computing — Vision Pro / Quest Overlay
**Technology:** visionOS / Quest MR APIs (future)

**What:** For spatial computing early adopters:
- Floating task cards in physical space ("sticky notes in the air")
- Emerald City dashboard as immersive environment during focus sessions
- Ambient Oz environments (walk the Yellow Brick Road while thinking)
- Spatial audio for focus sounds (rain from above, forest around you)

**Why it's blue ocean:** Zero ADHD apps exist for spatial computing. First-mover advantage in a growing platform.

#### 2.8 Smart Home Integration — Sensory Environment Control
**Technology:** HomeKit / Google Home / IFTTT APIs

**What:** Automatically adjust physical environment based on cognitive mode:
- Focus mode → dim lights, close blinds, set thermostat to 70°F, mute non-essential notifications
- Creative mode → warm lighting, ambient music via smart speaker
- Rest mode → turn off work lighting, gentle alarm
- ECO CODE mode → turn off unused smart devices

**Why it's blue ocean:** No ADHD app controls the physical environment. This bridges the digital-physical gap.

## 4. ADHD + Finance Research Summary

### Key Findings from Research

1. **ADHD and Impulse Spending:** Adults with ADHD are 4-5x more likely to make impulse purchases. The dopamine reward cycle drives spending as self-medication.

2. **Financial Consequences:** ADHD adults carry an average of $12,000 more in credit card debt than neurotypical peers. Late fees, forgotten bills, and impulse purchases compound.

3. **Existing Solutions Fall Short:** YNAB requires executive function to maintain budgets. Mint/Credit Karma are passive — they report but don't prevent. No app addresses the ADHD-specific emotional drivers of spending.

4. **What ADHD Users Need Financially:**
   - Automatic bill monitoring with past-due alerts
   - Impulse purchase cooling-off periods (24-48 hour delay)
   - Non-judgmental, compassionate alert language
   - Visual spending patterns (not spreadsheets)
   - Savings gamification that provides dopamine without spending
   - Emergency fund visibility ("You're safe" reassurance)

5. **Opportunity:** The intersection of ADHD productivity and financial management is a completely unserved market. No app combines cognitive awareness with financial guardianship.
