# Music Video Storage

All generated music videos are stored in this directory.

## Folder rule

Create one folder per song using kebab-case:

- `docs/videos-music/<song-name>/`

## Filename rule

Use UTC timestamp + versioning in the filename:

- `<song-name>-YYYYMMDDTHHMMSSZ-v<major>.mp4`

Example:

- `bulletproof-love-20260515T151936Z-v1.mp4`
