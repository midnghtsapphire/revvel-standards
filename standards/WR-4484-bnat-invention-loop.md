# WR-4484 — Autonomous BNAT Invention Loop (Human-Gated)

**Status:** rev-0 
**Band:** 44xx (Autonomy / Invention Systems) 
**Autonomy Directive:** 🟥 **HUMAN MERGE REQUIRED** — agents draft; humans decide, sign, and file. 
**Depends on:** WR-4483 (ensemble AHP + RICE decision scoring) 
**Prime Directive alignment:** $10k/mo → $10M/3yr — invention loop feeds the automated product pipeline (Focus Area 3) with vetted, IP-protected candidates before Polar.sh listing.

---

## 1. Purpose

Define a repeatable, auditable loop in which autonomous agents:

1. **Scan** for market/technical gaps ("BNAT" = *Best-Not-Available-Today*).
2. **Invent** candidate solutions.
3. **Screen** them with statistically honest kill discipline (DOE-5).
4. **Decide** using the WR-4483 ensemble AHP + RICE ranker.
5. **Build** Milestone-1 (M1) skeletons — code, spec, or bench artifact.
6. **Draft** IP artifacts (provisional-style disclosures, prior-art maps).
7. **Halt at a hard human-merge GATE** before any launch, listing, filing, or public disclosure.

No agent may launch, list on Polar.sh, file with the USPTO/EPO, or publish. Those acts require a named human of record.

## 2. Hard Constraints (non-negotiable)

| # | Constraint | Rationale / Citation |
|---|---|---|
| C1 | Agents **draft**; a named human is **inventor/author of record**. | *Thaler v. Vidal*, 43 F.4th 1207 (Fed. Cir. 2022); USCO *Copyright Registration Guidance: Works Containing Material Generated by AI* (Mar. 2023). |
| C2 | Agents **never** submit filings (USPTO, EPO, WIPO, trademark, copyright). | Same as C1; also USPTO *Inventorship Guidance for AI-Assisted Inventions* (Feb. 2024). |
| C3 | Agents **never** publish or list a product externally (Polar.sh, GitHub public release, HN, X). | Public disclosure starts the 12-month US grace period and destroys ex-US novelty. |
| C4 | Every stage output **must cite named math** used (see §5). Uncited scoring = auto-reject. | Auditability; prevents hand-wave scoring. |
| C5 | **DOE-5 kill discipline**: if fewer than ~40% of candidates entering Screen are killed at Screen, the batch is flagged for review. **0% kill rate is a red flag**, not a success. | Design-of-experiments: a screen that never rejects is not a screen. |
| C6 | Calibration target: rolling **Brier score < 0.20** on agent confidence vs. post-GATE outcomes. Approval rate is **not** a KPI. | Calibration > volume. |
| C7 | WIP cap per Little's Law: `WIP ≤ throughput × target_cycle_time`. Default WIP cap = **7 active candidates**. | Little's Law (L = λW). Prevents queue explosion. |
| C8 | GATE requires **two** human reviewers, at least one with legal/IP scope, before merge to `main`. | Separation of duties. |

## 3. Stage Pipeline

```
 SCAN → INVENT → SCREEN → DECIDE → BUILD-M1 → DRAFT-IP → 🟥 GATE 🟥 → (human) LAUNCH / FILE / LIST
```

Each stage emits a structured artifact under `wr4484/candidates/<slug>/<stage>.md` with a YAML front-matter block:

```yaml
stage: screen
candidate_id: bnat-2025-014
agent: openrouter:anthropic/claude-3.5
cited_math: [DOE-5, Ulwick-OS]
confidence: 0.62      # for Brier scoring
kill: false
timestamp: 2025-01-15T14:22:03Z
```

### 3.1 SCAN
- **Inputs:** market feeds, GitHub trending, Polar.sh funded issues, OSINT tool gaps, competitor changelogs.
- **Method:** Ulwick **Opportunity Score** = `Importance + max(0, Importance − Satisfaction)` on jobs-to-be-done extracted from user forums.
- **Output:** ranked gap list; top-N (default 20) forwarded to INVENT.
- **Cited math:** Ulwick Opportunity Score.

### 3.2 INVENT
- **Method:** TRIZ contradiction matrix + morphological analysis on each gap.
- **Output:** ≥ 3 distinct candidate solutions per gap (novelty enforced by requiring different TRIZ principles).
- **Cited math:** TRIZ 40 inventive principles.

### 3.3 SCREEN (kill stage — this is where most die)
- **Method:** DOE-5 factorial screen on {feasibility, novelty, defensibility, cost-to-M1, TAM proxy}. Agents must **actively argue for kill** on each candidate; the default is kill unless evidence justifies survival.
- **Prior-art check:** Google Patents + Lens.org + arXiv semantic search; any exact-match blocking claim → auto-kill.
- **Output:** survivor list + kill log with reasons.
- **Cited math:** DOE-5 fractional factorial; Brier calibration on kill/no-kill predictions.
- **KPI:** kill rate ≥ ~40% expected; deviations logged.

### 3.4 DECIDE
- **Method:** Invoke WR-4483 ensemble ranker — AHP pairwise on strategic weights, RICE on execution factors, ensemble score = geometric mean.
- **Output:** ranked survivor list with scores + sensitivity analysis (top result must survive ±20% weight perturbation).
- **Cited math:** Saaty AHP; Intercom RICE; geometric-mean ensemble (per WR-4483).

### 3.5 BUILD-M1
- **Definition of M1:** smallest artifact that lets a human evaluate the invention — runnable prototype, spec doc with worked example, or bench-measurable result.
- **WIP cap:** 7 (see C7).
- **Output:** branch `wr4484/<candidate_id>` with M1 artifact + README.
- **Cited math:** Little's Law WIP cap.

### 3.6 DRAFT-IP
- **Method:** Agent drafts (a) provisional-style technical disclosure, (b) prior-art map, (c) claim-scope sketch. **All marked `DRAFT — NOT FILED`**.
- **Output:** `wr4484/candidates/<slug>/ip-draft.md` — never submitted anywhere by the agent.
- **Cited math:** Prior-art recall estimate (bootstrap CI on search coverage).

### 3.7 🟥 GATE 🟥 (HUMAN MERGE REQUIRED)
- **Blocking checklist** (all must be ✅ before human merge):
  - [ ] All prior stages present and cite math (C4)
  - [ ] Kill log shows discipline (C5)
  - [ ] WR-4483 sensitivity analysis attached
  - [ ] IP draft reviewed by human with legal scope
  - [ ] Named human inventor/author of record recorded in `INVENTORS.md`
  - [ ] Two human reviewers approved PR (C8)
  - [ ] Brier score for the responsible agent still < 0.20 (C6)
- **Post-GATE actions (human-only):** launch, Polar.sh listing, USPTO filing, publication.

## 4. KPIs (what we actually track)

| KPI | Target | Why |
|---|---|---|
| Rolling Brier score (agent confidence vs. GATE outcome) | **< 0.20** | Calibration, not volume |
| Screen kill rate | **≥ 40%** | DOE-5 discipline |
| Cycle time SCAN → GATE | **≤ 14 days** | Feeds pipeline for $10k/mo phase |
| Active WIP | **≤ 7** | Little's Law |
| GATE human-review latency | **≤ 72h** | Prevents bottleneck |
| Post-GATE revenue attribution (Polar.sh + product) | tracked, not gated | Prime Directive |

## 5. Named-Math Registry (referenced by C4)

- **Ulwick-OS** — Opportunity Score = I + max(0, I − S)
- **TRIZ** — 40 inventive principles + contradiction matrix
- **DOE-5** — 2^(5−k) fractional factorial screen
- **AHP** — Saaty pairwise, consistency ratio ≤ 0.10
- **RICE** — Reach × Impact × Confidence / Effort
- **Brier** — mean squared error of probabilistic forecasts
- **Little's Law** — L = λW (WIP cap)

Any stage output citing math **not** in this registry must add it here in the same PR.

## 6. Legal Posture (summary — not legal advice)

- **Inventorship (US):** Only natural persons can be inventors on a US patent (*Thaler v. Vidal*, 2022). Agents may assist; a human must have made a *significant contribution* to at least one claim (USPTO 2024 guidance).
- **Authorship (US copyright):** Purely AI-generated material is not copyrightable (USCO 2023). Human selection/arrangement may be.
- **Trade secrets:** Preferred protection for internal M1 artifacts pre-GATE. Do **not** post to public repos before GATE.
- **Disclosure timing:** Public disclosure triggers the 12-month US grace period and forfeits absolute novelty in EPO/most ex-US jurisdictions. Agents therefore must not publish.
