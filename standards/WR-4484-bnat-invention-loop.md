## 1. Purpose

Define an **autonomous BNAT (Best-Not-Available-Today) invention loop** in which agents:

1. Scan for capability / market / IP gaps.
2. Invent candidate solutions.
3. Screen them under DOE-5 kill discipline.
4. Decide via the WR-4483 ensemble (AHP + RICE + calibrated forecast).
5. Build **M1 skeletons** (minimum-viable-artifact prototypes).
6. Draft IP artifacts (disclosures, claim scaffolds, prior-art maps).

All stages are **agent-drafted, human-decided**. No launch, listing, filing, or public commitment occurs without an explicit human merge.

---

## 2. Prime-Directive Alignment

This loop exists to compress the invention cycle so the $10k/mo → $10M/3y trajectory is achievable through a **portfolio** of small, killable bets rather than a single hero product. Kill discipline is how we protect burn; calibration is how we protect judgment.

---

## 3. Hard Constraints (non-negotiable)

> **HUMAN MERGE REQUIRED.** Agents may draft, propose, and prototype. Agents may **not**:
>
> - File patents, provisionals, or trademark applications.
> - Publish to package registries, app stores, or Polar/GitHub Sponsors listings.
> - Sign, click-accept, or transmit legal instruments.
> - Register the agent itself as inventor or author.
>
> **Legal basis:**
> - *Thaler v. Vidal*, 43 F.4th 1207 (Fed. Cir. 2022) — AI cannot be a named inventor under 35 U.S.C. § 100(f).
> - U.S. Copyright Office, *Copyright Registration Guidance: Works Containing Material Generated by Artificial Intelligence* (March 16, 2023) — human authorship required for registration.
>
> Humans are the **inventor / author of record**. Agent contributions are logged as tool-assisted drafting in the invention notebook.

## 4. Loop Stages

Each stage cites the named method it uses. Deviation requires a written rationale in the run log.

### 4.1 SCAN — Gap detection
- **Method:** Ulwick *Outcome-Driven Innovation* — compute **Opportunity Score = Importance + max(Importance − Satisfaction, 0)** per job-to-be-done.
- **Inputs:** issue backlog, competitor teardown notes, OSINT feed, Polar funding signals.
- **Output:** ranked gap list with Opportunity Scores ≥ 12 flagged as candidates.

### 4.2 INVENT — Candidate generation
- **Method:** TRIZ 40 inventive principles + analogical transfer across the ranked gap list.
- **Constraint:** minimum 5 candidates per gap; forced diversity via principle-tag coverage.
- **Output:** candidate register entries (title, hypothesis, principle tag, cost-of-attempt estimate).

### 4.3 SCREEN — DOE-5 kill discipline
- **Method:** Design-of-Experiments with **5 predefined kill criteria** set *before* data collection.
- **Rule:** any single kill-criterion failure → candidate is killed and archived. No revive without new information.
- **KPI guardrail:** the loop's rolling kill rate MUST land in **[40%, 85%]**. A 0% kill rate is a red flag (agents are rationalizing); a >85% kill rate means SCAN/INVENT are miscalibrated.

### 4.4 DECIDE — WR-4483 ensemble
- **Method:** ensemble of
  - **AHP** (Analytic Hierarchy Process, Saaty) for multi-criterion weighting,
  - **RICE** (Reach × Impact × Confidence / Effort) for shipping economics,
  - **Calibrated forecast** from agent + human (see §5).
- **Rule:** all three must clear their thresholds. Any single veto kills the candidate.

### 4.5 BUILD (M1) — Minimum-viable artifact
- **Method:** M1 skeleton — the *smallest* runnable/inspectable artifact that lets a human judge the invention.
  - Software: a failing test + a stub module + a README claim.
  - Physical: a CAD sketch + a bill-of-materials placeholder.
  - Process: a one-page SOP + a dry-run log.
- **WIP cap (Little's Law):** `WIP ≤ throughput × target-cycle-time`. Concretely: no more than **5 candidates in BUILD** at any time.

### 4.6 DRAFT-IP — Invention artifacts
- **Method:** agent drafts (a) invention disclosure, (b) claim scaffold, (c) prior-art map with citations.
- **Constraint:** every claim must reference at least one distinguishing feature vs. the prior-art map.
- **Output:** PR containing artifacts under `inventions/<slug>/` — **never** submitted externally by the agent.

### 4.7 GATE — Human merge
- **Reviewer checklist:**
  1. Kill criteria were defined *before* SCREEN data.
  2. DOE-5 log is complete and honest.
  3. Ensemble scores are reproducible from committed inputs.
  4. IP draft cites prior art; no agent listed as inventor/author.
  5. No external side effects were triggered by the agent run.
- **Only a human may:** merge the PR, initiate any filing, publish any listing, or release any funding call on Polar/Sponsors.

## 5. Calibration (the real KPI)

We optimize for **calibration**, not approval rate.

- **Metric:** Brier score on agent's stated probabilities for candidate-success predictions.
- **Target:** rolling **Brier < 0.20** over the last 30 decisions.
- **Consequence:** if Brier ≥ 0.20 for two consecutive review windows, SCAN/INVENT weights in the ensemble are down-weighted until calibration recovers.

Approval rate is *not* a KPI. Optimizing approval rate incentivizes flattery; optimizing Brier incentivizes honesty.
