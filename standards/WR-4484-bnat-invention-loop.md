# WR-4484 — Autonomous BNAT Invention Loop (human-gated)

**Status:** rev-0
**Band:** 44xx (Autonomy / Invention)
**Register:** wr-register
**Autonomy directive:** HUMAN MERGE REQUIRED

---

## 0. Purpose

Define an autonomous **B**uild-**N**egate-**A**ssess-**T**ransfer (BNAT) invention loop where LLM/agent tooling scans for opportunity gaps, invents candidate solutions, screens them with kill discipline, decides via a named-math ensemble, builds M1 (minimum-1) technical skeletons, and drafts IP artifacts — while a **hard human-merge gate** blocks any launch, listing, filing, or public disclosure.

Prime directive alignment: this loop feeds the $10k → $10M pipeline by increasing the *rate of vetted, defensible product/IP candidates per week*, not by autonomously shipping.

---

## 1. Hard constraints (non-negotiable)

These constraints are enforced in code (CI checks) and in review (CODEOWNERS on this file + any generated artifact).

1. **No autonomous filing.** Agents may draft provisional patent specs, trademark descriptions, and copyright deposit text. Agents **must not** submit to USPTO, USCO, EUIPO, WIPO, or any registrar. Filing is a human act.
2. **Human inventor/author of record.** Per *Thaler v. Vidal* (Fed. Cir. 2022) and USCO 2023 guidance (*Copyright Registration Guidance: Works Containing Material Generated by Artificial Intelligence*, 88 Fed. Reg. 16190), the inventor listed on any patent and the author claimed on any copyright must be a natural person. Agent contributions are disclosed as tooling, not authorship.
3. **No autonomous launch or listing.** Agents may prepare Polar.sh product drafts, GitHub release notes, and pricing pages, but the `publish`/`list`/`release` action requires a signed human merge of the artifact PR.
4. **No autonomous public disclosure.** Agents must not post to social, blogs, forums, or issue trackers of third parties. Draft-only.
5. **Kill discipline is a KPI, not a failure.** A 0% kill rate over a rolling 30-day window triggers a red-flag review — it means screening is broken, not that ideas are great.
6. **Calibration is the target metric.** Success of the loop is measured by **Brier score < 0.20** on agent forecasts of "will pass human gate," not by approval-rate or throughput.
7. **Little's Law WIP cap.** Concurrent BNAT candidates in-flight ≤ `WIP_MAX` (default 7). New SCAN outputs are queued, not started, when at cap.
8. **Named math or it didn't happen.** Every stage output must cite the specific method used (see §3). Un-cited scores are rejected by the ASSESS stage.

## 2. Stages (BNAT + SCAN + DECIDE + GATE)

```
SCAN → INVENT → SCREEN → DECIDE → BUILD(M1) → NEGATE → ASSESS → TRANSFER-DRAFT → [GATE: human merge] → (human) LAUNCH/FILE
```

### 2.1 SCAN — opportunity gap detection
- **Method:** Ulwick **Opportunity Score** = Importance + max(Importance − Satisfaction, 0), on jobs-to-be-done pulled from issue trackers, Polar funding requests, OSINT signal feeds, and GitHub trending gap analysis.
- **Output:** ranked gap list with Opportunity Score ≥ 12 threshold.
- **Autonomy:** full.

### 2.2 INVENT — candidate generation
- **Method:** **TRIZ** 40 inventive principles applied to top-N gaps; agents generate ≥ 3 orthogonal candidate approaches per gap (contradiction-matrix guided).
- **Output:** candidate cards `{gap_id, approach, triz_principles[], novelty_hypothesis}`.
- **Autonomy:** full.

### 2.3 SCREEN — DOE-5 kill discipline
- **Method:** **DOE-5** (Design-Of-Experiments, 5 kill criteria) — each candidate must survive 5 independent kill tests:
  1. **Prior-art kill:** semantic search of USPTO + Google Patents + arXiv; if ≥ 0.85 cosine to existing claim, KILL.
  2. **Market-size kill:** TAM < $1M/yr addressable → KILL.
  3. **Regulatory kill:** requires FDA/FAA/FCC approval that we cannot obtain in ≤ 24 months → KILL.
  4. **Build-cost kill:** M1 skeleton cost > $5k or > 40 eng-hours → KILL (unless Opportunity Score ≥ 18).
  5. **Moat kill:** no defensible moat (patent, data, network, brand, switching cost) → KILL.
- **Output:** survivors + kill log.
- **Autonomy:** full. **Kill rate target: 60–85%.**

### 2.4 DECIDE — WR-4483 ensemble (AHP + RICE)
- **Method:** ensemble decision per **WR-4483**:
  - **AHP** (Analytic Hierarchy Process, Saaty 1980) pairwise-compares survivors on {novelty, defensibility, revenue potential, time-to-M1, strategic fit}. Consistency Ratio must be < 0.10.
  - **RICE** (Reach × Impact × Confidence / Effort) computed independently.
  - Ensemble = normalized rank-average. Ties broken by Opportunity Score.
- **Output:** ordered build queue, capped at `WIP_MAX`.
- **Autonomy:** full.

### 2.5 BUILD (M1) — minimum-1 skeleton
- **Method:** smallest working artifact that instantiates the invention. Code repo scaffold, one runnable path, one test, one README. No polish, no marketing.
- **Output:** branch `bnat/<candidate_id>` with M1 skeleton.
- **Autonomy:** full (branch only, no merge to main).

### 2.6 NEGATE — adversarial self-review
- **Method:** a second agent instance, prompted adversarially, attempts to *falsify* the invention: reproduce with prior art, break the moat, find a cheaper substitute, or show the market doesn't want it.
- **Output:** negation report. If negation succeeds on any DOE-5 axis, candidate returns to KILL.
- **Autonomy:** full.

### 2.7 ASSESS — calibration & scoring
- **Method:** agent emits a **forecast probability** `p ∈ [0,1]` that the candidate will pass the human gate. This forecast is logged. After the gate resolves, **Brier score** = (p − outcome)² is appended to the calibration ledger.
- **Rolling target:** Brier < 0.20 over last 20 candidates.
- **Autonomy:** full.

### 2.8 TRANSFER-DRAFT — IP & product artifact drafting
- **Method:** agent drafts, in a PR, any subset of:
  - Provisional patent specification (35 U.S.C. §111(b) format)
  - Trademark identification-of-goods draft
  - Copyright deposit text (with AI-disclosure block per USCO 2023)
  - Polar.sh product listing draft (title, description, price tier)
  - GitHub release notes draft
  - Landing page copy
- **Constraint:** every artifact carries the header:
  ```
  DRAFT — AI-ASSISTED — NOT FOR FILING OR PUBLICATION WITHOUT HUMAN REVIEW
  Human inventor/author of record: <to be filled by reviewer>
  Agent tooling disclosure: <model, version, date>
  ```
- **Autonomy:** full (PR only).

### 2.9 GATE — human merge required
- **Method:** PR review by a named human maintainer (CODEOWNERS). Reviewer must:
  1. Confirm inventor/author name is filled.
  2. Confirm no DOE-5 kill was suppressed.
  3. Confirm the forecast `p` was logged before this review (no post-hoc calibration).
  4. Sign the merge (`Signed-off-by:` trailer).
- **Only after merge** may a human take the file/list/launch action.
- **Autonomy:** ZERO. This is the hard gate.

## 4. KPIs

| KPI                              | Target             | Red flag                    |
|----------------------------------|--------------------|-----------------------------|
| DOE-5 kill rate (30-day)         | 60–85%             | < 40% or = 100%             |
| Brier score (rolling 20)         | < 0.20             | > 0.30                      |
| Human-gate approval rate         | *not a target*     | (informational only)        |
| Candidates → M1 → gate / week    | ≥ 2                | 0 for 2 consecutive weeks   |
| WIP in flight                    | ≤ `WIP_MAX` (7)    | > `WIP_MAX`                 |
| Suppressed-kill incidents        | 0                  | ≥ 1 (post-mortem required)  |

## 5. Failure modes & guardrails

- **Sycophantic screening** (agent avoids killing its own ideas): mitigated by using a **separate agent instance** for NEGATE, and by the kill-rate red flag.
- **Prior-art blindness:** SCREEN prior-art check must query at least 2 independent corpora (USPTO + one of {Google Patents, Lens.org, arXiv}).
- **Calibration drift:** if Brier > 0.30 for 20 candidates, freeze the loop and retrain/re-prompt.
- **Legal drift:** any change to §1 requires CODEOWNERS sign-off from a human with legal-review authority.
- **Disclosure leakage:** agents run in a network policy that blocks POST to `uspto.gov`, `copyright.gov`, `euipo.europa.eu`, `wipo.int`, `polar.sh` publish endpoints, and social APIs. Draft artifacts live in-repo only until human merge.

## 6. Prime-directive linkage

This loop is a **rate multiplier** for Phase 1 → Phase 4:

- Phase 1 ($10k/mo): 2–4 vetted Polar.sh product drafts per month through the gate.
- Phase 2 ($30k/mo): OSINT tool candidates dominate the queue; DOE-5 tuned for OSINT moats.
- Phase 3 ($100k/mo): provisional patents from TRANSFER-DRAFT begin to compound as defensible moats.
- Phase 4 ($10M total): IP portfolio + product portfolio, both human-signed, both defensible.

The loop never sells, files, or ships on its own. It **manufactures reviewed options** at a rate humans alone cannot sustain.
