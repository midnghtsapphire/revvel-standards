# Archived issue templates

These were retired from `.github/ISSUE_TEMPLATE/` so the New Issue chooser shows
only **OpenHands Work Request** (single, unambiguous intake).

| File | Why archived |
| ---- | ------------ |
| `daily-decision.md` | Triage proposal flow. Now handled by `issue-auto-triage.yml` + Project v2 board, no separate template needed. |
| `exit-quiet-mode.md` | One-time permission gate. Use `workflow_dispatch` on the relevant workflow if needed again. |
| `issue.yml` | Earlier "one template for everything" form. Superseded by `00-OpenHands-work-request.yml`, which is shorter, has `auto-classify` defaults, and feeds the auto-classifier workflow. |
| `urgent-compliance.md` | Compliance-watcher alert. Compliance alerts are now generated by automation (label-driven), not human-filed. |
| `work-request.yml` | Earlier draft of the WR form. Superseded by `00-OpenHands-work-request.yml`. |

**To restore any of these into the chooser**, move the file back to
`.github/ISSUE_TEMPLATE/`. The order in the chooser is `.yml` before `.md`,
each group sorted alphabetically by filename, so use a numeric prefix
(`01-`, `02-`, etc.) if you want a specific ordering.
