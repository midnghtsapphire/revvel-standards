# Revvel Emblem Standard — Design Formula for Every Revvel App

**Version:** 1.0.0
**Date:** April 2026
**Scope:** All Revvel/MIDNGHTSAPPHIRE projects
**Formula Type:** Revvel Emblem Standard

The Revvel Emblem Standard is the universal visual design formula for every Revvel and MIDNGHTSAPPHIRE project. It defines how to create a layered, machine-like shield emblem specific to each project's purpose — derived from the project's core topic and user metaphor. GrowlingEyes is the reference implementation.

---

## Section 1: What Is the Revvel Emblem Standard

The **Revvel Emblem** is a highly detailed, skeuomorphic-yet-digital shield. It bridges institutional knowledge (metal, glass, depth, weight) with cutting-edge data analysis (circuits, holograms, crystalline data). The result looks heavy, functional, and **active** — like a physical machine performing its purpose.

**Core tension:** It should feel like something you could hold in your hand AND like it's running complex operations in real time.

**Why this formula exists:** Generic logos are forgettable. The Revvel Emblem formula forces every visual element to be *derived* from the project's actual purpose. This means the logo communicates function, not just aesthetics.

## Section 2: The Derivation Chain

Every design element must trace back through this chain. Start at the top, derive each level before moving to the next.

```text
Project Topic
    ↓
User Metaphor (the "feeling" the user describes — e.g., "digital growl")
    ↓
Visual Translators (what does each element of the metaphor LOOK like?)
    ↓
Layer Assignment (which Revvel Emblem layer does each visual go on?)
    ↓
Color Conversion (apply project palette using the Revvel Emblem Color Conversion formula)
```

|---|---|

## Section 3: The 5-Layer Revvel Emblem Stack

Build the emblem in these layers, bottom to top.

---

### Layer A — The Base Casing (Institutional Shell)

**What it is:** The outer protective structure of the emblem. This is the first thing you see — the frame that says "this is a serious machine."

**Texture requirements:**
- Thick frosted glass dome, semi-transparent (you can see the layers beneath)
- Soft cold blue and gold internal glow emanating from within the dome
- Frame: Thick outlined metal shell — **burnished brass by default**; use project-specific material when derived (see Per-Project Icon Derivation Guide)

**Defensive detail (REQUIRED, derived from topic):**
This layer must include a defensive/adversarial detail derived from the project's core tension. The detail represents the "shield" aspect — what the system is protecting against or fighting.

| Project Type | Derived Defensive Detail |
|---|---|
| Surveillance / OSINT | Fangs, sharp angular protrusions |
| Finance / Payments | Vault door segments, thick bolt locks |
| Agriculture / Nature | Stylized roots or grain stalks as structural reinforcement |
| Health / Medical | Double helix DNA strands as the frame structure |
| Music / Creative | Sound wave ridges along the frame edge |

---

### Layer B — The Central Thought (Main Data Core)

**What it is:** The heart of the emblem. The organic element that grounds the entire design in something human and real.

**Texture requirements:**
- High-resolution organic texture derived from topic (examples: human iris, water droplet, DNA strand cross-section, soil cross-section, vinyl record groove)
- **REQUIRED:** Crystal-clear deep-domed glass lens covering the core — the lens must sit visibly above the organic layer
- **CRITICAL:** The lens surface MUST have a unique ripple/wave pattern — specular highlights that appear to actively ripple and distort as if the lens is alive

**The ripple pattern is non-negotiable.** It is the visual metaphor for "data flowing through the system." Static glass is not acceptable.

---

### Layer C — The Internal Data Stream (Recursion)

**What it is:** Visible through the rippling glass lens — the computational process happening inside the system.

**Requirements:**
- Detailed circuit board pattern integrated into the central core, visible through the glass lens of Layer B
- **CRITICAL:** At the very center of the circuit board, a single complex **golden digital cluster** or **crystalline data solution** — the output of the system represented as a physical object
- The crystal/cluster must appear to be generating light (it is the source of the internal glow)

**The golden crystal is the visual answer to the question: "What does this system produce?"**

| Project | Central Crystal Represents |
|---|---|
| GrowlingEyes | Uncovered truth — gold crystal of knowledge |
| Finance app | Accurate financial insight — geometric gold coin-crystal |
| Music app | Perfect sound wave — crystalline audio frequency visualization |
| Health app | Diagnosis output — DNA/crystalline molecular structure |

---

### Layer D — The Outer Nodes (Functional Circuitry)

**What it is:** The outer layer of the glass dome, etched with circuit line patterns and functional icons that represent what the system does.

**Requirements:**
- Frosted glass circuit line patterns, etched INTO the outer shell (not floating above it)
- Softly lit from within (the internal glow from Layer C passes through these etchings)
- **4–6 topic-derived functional icons** positioned at key circuit nodes (see Section 6 for derivation guide)
- Each icon appears "active" — lit from within, not just flat symbols

**The icons must be FUNCTIONAL (what the system does), not thematic (what it looks like).**

---

### Layer E — Text, Cables, and Inputs/Outputs

**What it is:** The layer that makes the emblem feel like a real machine connected to the world.

**Requirements:**
- **Multiple text blocks:** Main header banner with project name (repeated or wrapped around the emblem) + definitive solution statement at the base
- **Physical cables** with multi-material connections: red/silver/gold/fiber optic — at least 3 cable types
- **Large complex data-structure at the base:** A wire grid, circuit traces, or data visualization that grounds the floating machine into "infrastructure"
- **Function:** Sells the feeling that this emblem is a port on a much larger physical machine

## Section 4: Universal Color Conversion Formula

Steps to apply any 4-color palette to the Revvel Emblem system:

### Step 1: Define User Colors

The project defines exactly 4 brand colors:
- **Primary** — the dominant brand color (often a dark or rich tone)
- **Secondary** — the most intense/contrasting color
- **Accent** — the highlight/glow color
- **Background** — the base/neutral color

### Step 2: Assign to Revvel Emblem Roles

| Revvel Emblem Role | Color Assignment | Material Effect |
|---|---|---|
| Primary Casing (frosted dome + outline) | User **Primary** | Apply frosted glass effect — slightly translucent, not solid |
| Adversarial/Defensive Accent (sharp details, intensity points) | User **Secondary** (most intense) | Hard edge, high contrast, almost aggressive |
| Organic/Textural Core | User **Primary + Accent** gradient | Smooth gradient, natural feel |
| Data Production (holograms, internal glows, solution crystal) | User **Accent** (dominant glow color) | Luminescent, appears to emit light |
| Node/Text Emanation (etched circuits, softly lit text) | User **Background** color, softly integrated | Barely visible, whisper-level luminance |

### Step 3: Apply Material Effects

- **Frosted glass** on casing — reduce opacity 15–30%, add slight blur and refraction
- **Metal sheen** on frame — linear gradient with sharp highlight at top edge
- **Glow on data nodes** — radial gradient, ~40% opacity at edge, 100% at center
- **Dark shadows behind casing** — deep shadow layer, makes the emblem appear to float above the surface

### Step 4: Maintain the Depth

The depth gradient (dark at the edges, bright at the center) must always be maintained. The center — the golden crystal — must be the brightest point in the entire emblem.

### GrowlingEyes Example

| Revvel Emblem Role | GrowlingEyes Color |
|---|---|
| Primary Casing | Teal — `#0D9488` (frosted teal dome) |
| Adversarial Accent | Red — `#DC2626` (fang outlines, intensity points) |
| Organic Core | Teal + Red gradient (iris base transitions from teal to red near edge) |
| Data Production | Gold — `#F59E0B` (hologram glow, crystal in center) |
| Node/Text | White — `#F8FAFC` (softly lit on teal glass) |

## Section 5: The Golden Formula

```text
Revvel Emblem = (Derivation × Metaphor Stack) + Integrated Logic
```

### Implementation Checklist

Every Revvel Emblem commission or generation must complete all items:

- [ ] Define Topic/Goal → derive initial metaphors
- [ ] Define User Metaphor Input → derive adversarial/protective elements
- [ ] Apply Layer A: Topic-derived Base Casing with frosted metal shell + internal glow
- [ ] Apply Layer B: Adversarial/defensive detail integration into the casing
- [ ] Apply Layer C: Topic-derived Central Thought (hyper-detailed organic texture + rippling glass lens)
- [ ] Apply Layer D: Recursion layer (visible circuit pattern through glass + central glowing data crystal)
- [ ] Apply Layer E: Functional Nodes (etched circuit nodes with 4–6 derived icons)
- [ ] Apply Layer F: Inputs/Outputs (physical cables + base data grid)
- [ ] Apply Layer G: Multiple integrated text blocks (project name header + solution statement at base)
- [ ] Apply Color Conversion Formula (4 colors → 5 Revvel Emblem roles)
- [ ] Verify depth gradient: center bright (gold crystal) → edge dark (shadow)
- [ ] Deliver all required asset sizes (see `BRAND_IDENTITY_TEMPLATE.md` Asset Delivery Checklist)

## Section 6: Per-Project Icon Derivation Guide

The 4–6 functional icons in Layer D must be derived from the project's core functions.

### Derivation Process

1. List the project's 4–6 core **functions** (not features — functions: what does it DO at a fundamental level?)
2. Find the simplest icon that represents each function
3. Assign to Layer D node positions (typically: top-left, top-right, bottom-left, bottom-right, with 1–2 at mid-sides)

| Project Type | Core Functions | Derived Icons |
|---|---|---|
| OSINT / Surveillance | Monitor public data, analyze patterns, identify actors, deny access, alert | megaphone, bar chart, avatar+, microchip, lock, globe |
| Finance / Payments | Process payments, track balances, transfer funds, secure accounts, report | dollar sign, chart-up, shield, wallet, transfer arrows, report |
| Health / Medical | Track vitals, analyze data, prescribe/recommend, monitor progress | heartbeat, microscope, pill/capsule, DNA strand, clipboard |
| Music / Creative | Record, mix, publish, distribute, analyze performance | waveform, musical note, microphone, vinyl record, equalizer |
| Education / Learning | Teach, assess, track progress, certify | book, pencil, checklist, graduation cap, chart |
| E-commerce | Browse, purchase, track, review, support | shopping cart, credit card, package, star, chat bubble |
