## Overview

This template provides a **production-ready glassmorphic dark UI** that can be deployed instantly as a live HTML dashboard. No build step required—pure HTML/CSS/JS that can be hosted anywhere.

## Features

- Glassmorphic dark design (warm gold accents)
- Responsive layout (mobile-first)
- Scroll animations
- No dependencies required
- SEO-optimized meta tags
- Accessible color contrasts
- Grid background with noise overlay

## Quick Deploy Options

### Option 1: GitHub Pages (Recommended)

1. Create a new repo: `audrey-[project]-portfolio`
2. Push `index.html` to `main` branch
3. Enable GitHub Pages in Settings > Pages > Source: main
4. Access at: `https://[username].github.io/[repo-name]`

### Option 2: Vercel (Zero Config)

```bash
npm i -g vercel
cd [project-folder]
vercel --prod
```

### Option 3: Netlify (Drag & Drop)

1. Go to [app.netlify.com/drop](https://app.netlify.com/drop)
2. Drag the folder containing `index.html`
3. Done!

## Customization

Colors use CSS variables for easy theming:

```css
:root {
    --bg-deep: #0a0a0f;
    --accent-gold: #d4a853;
    --accent-emerald: #34d399;
}
```
