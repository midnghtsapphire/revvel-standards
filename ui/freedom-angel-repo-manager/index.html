3. Repositories

About this audit

This dashboard audits each repository against the Revvel Standards Master Inventory. Checks include:

  • README.md present
  • LICENSE present
  • CHANGELOG.md present (auto-documentation)
  • .github/workflows/ present (CI / CD automation)
  • SECURITY.md or security.yml workflow
  • Standard labels (enhancement, bug, security, documentation)
  • Accessibility reference (accessibility word appears in README)
  • Mentions revvel-standards (inheritance from SSOT)

Results are read-only — nothing is written to GitHub. All data stays in your browser.
