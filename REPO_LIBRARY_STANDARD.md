# Repo Library Standard

**Rule:** Every new repo must have a `Library/` folder at its root.

## What goes in Library/
- Source documents the repo's work relies on: PDFs, journal articles, scans, letters, reference books, datasets.
- Private repos keep the full files. Do not exclude PDFs or other sources by `.gitignore`.

## Requirements
1. Create `Library/` with a `README.md` when the repo is created.
2. The README lists what is held, one line per item (author, year, title, filename).
3. Agents put new sources in `Library/`, not in local drives, OneDrive, or scratch folders.
4. Existing repos add `Library/` when next touched.
