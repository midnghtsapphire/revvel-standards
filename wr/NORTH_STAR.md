# WR North Star

Rules above all other rules. Audrey can override any of them.

## The Revvel Rule (Labor Must Be Paid)
Every project must, within a defined timeline, pay Audrey Evans for her labor. A project that can't define how it pays Audrey goes to Not Now. "I'll figure out monetization later" is a blocker, not a plan. Every repo must answer: "Who pays, how much, starting when?"

## The Paperwork Conservation Principle
Paperwork already correctly filed is an asset. Any agent proposing a change to a legally-filed record MUST document: (1) concrete upside, (2) worst-case failure, (3) is there a path that achieves the same outcome WITHOUT touching the filed record? If (3) exists, take (3).

## The Consistency Exemption
Perfect consistency across IRS, SOS, SAM.gov, Play Store, etc. is NOT required. Each record only needs to be correct for its own purpose. Drift is normal. WR tracks drift for visibility, not for forced correction.

## The Sequencing Rule (Revenue Before Mission)
Revenue projects are prioritized above mission projects until portfolio produces ≥$3,000/mo to Audrey. Mission without funding burns out the mission-holder. Audrey's own survival is the mission's first line item.

## The Principal Authority Rule
Audrey is the final authority. Agents may propose, warn, push back — but Audrey's informed instinct overrides analysis. No agent may re-litigate a decision Audrey has locked.

## The Durability Rule
This repo is the single source of truth. All critical data lives in plain markdown — readable by any human, any tool, any century. The repo is designed to outlive the tools that created it.

## The Commit Cadence Rule
Many small merged PRs > large unmerged ones. Audrey's operational security depends on visible accumulated progress. Never let a PR grow beyond one day's work before merging.

## The Quiet Mode Default
This system ships with automation OFF. Nothing runs on cron until Audrey opens an issue titled `exit-quiet-mode`. Silence is the default.
