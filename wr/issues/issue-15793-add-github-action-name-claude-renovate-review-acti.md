Claude Renovate Review Action
GitHub LicenseGitHub Actions Workflow Status

Review Renovate PRs using Claude Code.

Usage
name: Claude Renovate Review

on:
  pull_request:
    types:
      - opened
      - edited

jobs:
  claude-renovate-review:
    if: github.event.pull_request.user.login == 'renovate[bot]'
    runs-on: ubuntu-latest
    permissions:
      contents: read
      pull-requests: write # for commenting on the PR
    steps:
      - uses: actions/checkout@v4
      - uses: koki-develop/claude-renovate-review@v1
        id: review
        with:
          anthropic-api-key: ${{ secrets.ANTHROPIC_API_KEY }}
          # or
          claude-code-oauth-token: ${{ secrets.CLAUDE_CODE_OAUTH_TOKEN }}

      # Use the safety-assessment output
      - name: Check safety assessment
        run: echo "Safety Assessment: ${{ steps.review.outputs.safety-assessment }}"
Using the safety-assessment output
You can use the safety-assessment output to automate PR workflows based on the safety level.

Auto-approve safe PRs
- name: Auto-approve if safe
  if: steps.review.outputs.safety-assessment == 'safe'
  run: gh pr review "$PR_NUMBER" --approve
  env:
    GITHUB_TOKEN: ${{ github.token }}
    PR_NUMBER: ${{ github.event.pull_request.number }}
Auto-merge safe PRs
- name: Auto-merge if safe
  if: steps.review.outputs.safety-assessment == 'safe'
  run: gh pr merge "$PR_NUMBER" --auto
  env:
    GITHUB_TOKEN: ${{ github.token }}
    PR_NUMBER: ${{ github.event.pull_request.number }}

### Definition of Done

The GitHub Action workflow file (.github/workflows/claude-renovate-review.yml) is created and configured to trigger on Renovate bot pull requests. The action successfully integrates with Claude AI to provide automated code reviews of dependency updates. All required secrets (ANTHROPIC_API_KEY or claude-code-oauth) are configured in repository settings. The workflow has appropriate permissions for reading contents and writing pull request comments, and testing confirms it activates only for renovate[bot] authored PRs.

### Do Not Under-Scope

Ensure the GitHub Action properly integrates with existing CI workflows and doesn't conflict with the current trusted bot auto-approval system. Verify that Claude's review comments don't interfere with the pr-state-orchestrator's label progression logic. Test that the action correctly identifies renovate[bot] PRs and that the ANTHROPIC_API_KEY secret is properly configured. Don't skip validation of the action's permissions scope and ensure it works alongside existing security checks like GitGuardian.

### Explicit Exclusions

This work request excludes manual review processes for Renovate PRs, integration with non-Claude AI review systems, and modification of existing trusted bot approval workflows. The scope does not include setting up Anthropic API keys or Claude Code OAuth configuration, as these are infrastructure concerns outside the GitHub Action file creation. Additionally, this excludes creating comprehensive testing frameworks or documentation beyond basic usage examples.
