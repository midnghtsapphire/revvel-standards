ClinicalTrials.gov: NCT04165226

**Paper summary:** Randomized controlled study (n=30, skin phototypes III–IV) comparing:
1. Photobiomodulation / LLLT only (808 nm infrared diode)
2. Fractional CO₂ laser only
3. Combined LLLT + fractional CO₂ laser

**Key findings:** LLLT was statistically comparable in efficacy to fractional CO₂ for stria alba;
no downtime (higher patient satisfaction); requires more sessions (8–12 vs 2 monthly CO₂). Combination
therapy did not outperform either monotherapy.

**Request tags:** #tools #app — build a clinical decision-support tool and/or consumer app around this evidence base.

## 1. Executive Decision

**Build Decision: PROCEED — strong niche, validated clinical evidence, minimal direct competition**

The paper (doi: 10.1007/s10103-024-04107-x, [PMC11189306](https://pmc.ncbi.nlm.nih.gov/articles/PMC11189306/))
provides defensible level-II evidence to power both a **professional clinical decision-support (CDS) tool**
and a **consumer education/self-assessment app** for stretch-mark treatment selection.

Market gap identified: no agnostic, evidence-based CDS app exists for photobiomodulation vs. ablative laser
selection in striae distensae. Existing solutions are device-manufacturer companion apps (protocol timers,
reminders) rather than treatment-selection engines.

### Fix 1: Protocol Engine Core
```typescript
// File: src/lib/protocolEngine.ts
export type FitzpatrickType = 'I' | 'II' | 'III' | 'IV' | 'V' | 'VI';
export type StriaType = 'alba' | 'rubra';
export type Modality = 'PBM' | 'CO2_fractional' | 'combined';

export interface ProtocolRecommendation {
  modality: Modality;
  sessions: number;
  intervalWeeks: number;
  rationale: string;
  citation: string;
  contraindications: string[];
}

/**
 * Evidence-based protocol selector for stria distensae treatment.
 * Source: doi:10.1007/s10103-024-04107-x (Lasers Med Sci. 2024;39(1):159)
 */
export function recommendProtocol(
  fitzpatrick: FitzpatrickType,
  striaType: StriaType,
  downtimeTolerance: 'none' | 'moderate' | 'high'
): ProtocolRecommendation {
  // For stria alba with no downtime tolerance → PBM (LLLT 808nm)
  if (striaType === 'alba' && downtimeTolerance === 'none') {
    return {
      modality: 'PBM',
      sessions: 10, // 8-12 sessions per RCT
      intervalWeeks: 1,
      rationale: 'LLLT was statistically comparable in efficacy to fractional CO2 for stria alba with zero downtime and higher patient satisfaction in phototypes III-IV.',
      citation: 'Lasers Med Sci. 2024;39(1):159. doi:10.1007/s10103-024-04107-x',
      contraindications: ['Active photosensitivity', 'Active skin infection', 'Pregnancy (caution)'],
    };
  }
  // Default to CO2 fractional for high downtime tolerance
  return {
    modality: 'CO2_fractional',
    sessions: 2,
    intervalWeeks: 4,
    rationale: 'Fractional CO2 laser showed numerically higher improvement for stria alba; suitable when patient can tolerate downtime.',
    citation: 'Lasers Med Sci. 2024;39(1):159. doi:10.1007/s10103-024-04107-x',
    contraindications: ['Active photosensitivity', 'Active skin infection', 'Pregnancy', 'Fitzpatrick V-VI (increased PIH risk)'],
  };
}
```

```typescript
const ABSOLUTE_CONTRAINDICATIONS = [
  'Active infection at treatment site',
  'Active malignancy',
  'Photosensitizing medications (isotretinoin within 6 months for CO2)',
  'Pregnancy',
];

export function screenContraindications(patientFlags: string[]): string[] {
  return ABSOLUTE_CONTRAINDICATIONS.filter(c =>
    patientFlags.some(f => c.toLowerCase().includes(f.toLowerCase()))
  );
}
```
