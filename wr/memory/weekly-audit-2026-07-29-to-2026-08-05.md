# Weekly audit method memory — 2026-07-29 → 2026-08-05 (refreshed 2026-08-08)

Companion to `wr/pending/weekly-audit-2026-08-05/README.md` and issue #16947.

## What worked

1. **Re-query live PR state before acting on a multi-day audit issue.** The
   2026-08-05 body listed #16944 / #16928 / #16897 / #16939 as open blockers;
   by 2026-08-08 all four were already merged. Shipping “fix lint on #16944”
   would have been wasted work.
2. **Read failing allowlist/governance job logs, not just labels.** #16929
   wore both `checks-passing` and `status:checks-failing`. The real blocker
   was `UNKNOWN labels: ready-to-merge` from `label-allowlist-check.mjs`
   after the governance pack landed.
3. **Treat fleet labels as first-class allowlist entries when bots apply the
   bare name.** Aliasing only `status:ready-to-merge` is not enough if
   lifecycle workflows also stamp bare `ready-to-merge`.
4. **Keep human_gate intact.** Audit PRs should fix automatable CI gaps and
   document click-by-click merge steps; they should not undraft/merge sibling
   PRs.

## False leads

- “Sheaf cluster still needs a human pick” — false by 2026-08-08; #16897
  already merged. Remaining work is **closing duplicates**, not choosing.
- “#16944 still needs lint fix” — false; already on `main`.
