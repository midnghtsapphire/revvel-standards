# ROADMAP: Music Video Creator

## Phase 1: MVP (Month 1)
- Setup EXRUP required artifacts.
- Scaffold Next.js application with Tailwind CSS.
- Build landing page UI.
- Implement file upload components (.wav and images).
- Mock/stub Video Generation API orchestration.
- Integrate mandatory affiliate and newsletter modules.
- Deploy to Vercel.

## Phase 2: Core Integration (Month 2)
- Wire up real API keys for Luma/Runway/HeyGen.
- Implement real-time video generation progress tracking.
- Set up secure media storage.

## Phase 3: Monetization & Scale (Month 3)
- Introduce premium paid generation credits.
- Advanced export formats.
- Integration with external social posting tools.
