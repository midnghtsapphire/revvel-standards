# Music Video Creator

Music Video Creator is a production-ready application to generate automated music videos from .wav files and avatar images using multiple AI video generation APIs. Built according to EXRUP methodology.

## 🚀 Live Product

**Location:** `products/music-video-creator/`
**Description:** Music video generator using AI apis for video
**Revenue Model:** Premium video generations, subscriptions, affiliate links

## 🛠️ Tech Stack

- **Framework:** Next.js 14 with App Router
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Deployment:** Vercel

## 🏃 Quick Start

Run `npm install` and then `npm run dev` to start the development server.
