# High-Ticket Affiliate Hub

## Live Deployment

▶️ **[Open the live app & test it](https://midnghtsapphire.github.io/revvel-standards/docs/affiliate-hub/)**

## Features

- 🎯 **10+ Premium Programs** - Curated list of the highest-paying affiliate programs
- 🔍 **Smart Search** - Find programs by name or target audience
- 📊 **Advanced Filtering** - Filter by commission type (recurring, one-time, hybrid)
- 💰 **LTV Comparison** - Compare lifetime values across programs
- 🎨 **Beautiful UI** - Modern, responsive design with dark mode support
- ⚡ **Fast Performance** - Built with Next.js for optimal speed

## Tech Stack

- **Framework:** Next.js 14 with App Router
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Deployment:** Vercel (static export)

## Getting Started

### Prerequisites

- Node.js 18+ 
- npm or yarn

### Installation

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

## Development

The application runs on `http://localhost:3001` by default.

```bash
npm run dev     # Start development server
npm run build   # Build for production
npm run start   # Start production server
npm run lint    # Run ESLint
```

## Deployment

This application is configured for static export and can be deployed to Vercel, Netlify, or any static hosting service.

### Deploy to Vercel

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/midnghtsapphire/revvel-standards/tree/main/products/affiliate-hub)

Or manually:

```bash
npm run build
# Upload the 'out' directory to your hosting provider
```
