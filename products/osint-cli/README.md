# OSINT CLI

> Fast, scriptable open-source intelligence toolkit. Phase 1 revenue anchor.

## Value Prop
One CLI + API for domain, email, username, and breach intel — priced for solo
researchers and small security teams.

## Pricing
| Tier   | Price      | Limits                        |
|--------|------------|-------------------------------|
| Free   | $0         | 100 queries/day, CLI only     |
| Pro    | $29/mo     | 10k queries/mo, API access    |
| Team   | $299/mo    | 100k queries/mo, 5 seats, SSO |
| Enterprise | Contact | Unlimited, on-prem option  |

Billing via [Polar.sh](https://polar.sh).
