## 🚀 Quick Start

### Run Locally

```bash
# Install dependencies
cd products/affiliate-hub && npm install
cd ../ai-video-toolkit && npm install
cd ../screen-recorder-finder && npm install

# Run dev servers (separate terminals)
cd products/affiliate-hub && npm run dev        # http://localhost:3001
cd products/ai-video-toolkit && npm run dev     # http://localhost:3002
cd products/screen-recorder-finder && npm run dev  # http://localhost:3003
```

### Deploy to Vercel

```bash
# Option 1: Vercel CLI
npm install -g vercel
cd products/affiliate-hub && vercel --prod
cd ../ai-video-toolkit && vercel --prod
cd ../screen-recorder-finder && vercel --prod

# Option 2: Vercel Dashboard
# Import repo → Set root directory → Deploy
```
