# Beauty Kit (incubating)

Status: incubating research. Not built, not published, not for sale yet.

The Beauty Kit is the planned family of theme packs, README kits, icon packs, and how-to booklets
that make black and generic tools look beautiful, for AudreyBuildsAI / Freedom Angel Corp. The look
is retro arcade, soft Hawaiian, bright, and accessible-contrast.

## What is here

- [`RESEARCH-beauty-playbook.md`](RESEARCH-beauty-playbook.md): the BALLS Beauty Playbook. It covers
  GitHub beautification (built-in themes, extensions, profile README tricks, README design, Pages
  themes), the same ideas for VS Code/Cursor, terminals, Notion, Linear, Gmail, Chrome, and Windows
  11, real market prices for similar products with verified URLs, and eight proposed products.

## Rules for this folder

- Incubates under `products/beauty-kit/` per `standards/PRODUCT_INCUBATION_STANDARD.md`.
- Nothing is published, listed, or sold without Audrey's explicit yes.
- No affiliate links and no tracking. Everything stays free of paid GitHub features.
- Original art only. Do not copy trademarked themes or characters (no Pac-Man or Mario names or
  shapes). Respect open-source licenses: keep the MIT notice on any remix, and do not reuse
  proprietary themes such as Dracula Pro.
