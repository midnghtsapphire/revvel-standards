# Hula Arcade README Kit (Lite): Start Here

You have one profile layout and its light and dark pixel banner. It is free (MIT license). Enjoy it, and come back for the Pro kit if you want more.

## Set up in 3 steps

1. Create a **public** repository named exactly like your GitHub username (for `octo-fan`: `octo-fan/octo-fan`) and tick "Add a README".
2. Copy `README.md` over the README in that repository, and copy the whole `assets/` folder next to it.
3. Open the README, search for **EDIT**, and swap in your own words.

The banner uses a `<picture>` element, so visitors see the light banner in light mode and the dark banner in dark mode. All pictures have alt text.

## Make your own banner text (optional)

```bash
python3 scripts/make_banner.py --layout minimal --title "ALOHA!" --tagline "HELLO FROM MY CORNER" --out assets/banners
```

Python 3.8 or newer, nothing to install. Letters, numbers and `. , ! ? - : / ' + # ( ) &` work.
