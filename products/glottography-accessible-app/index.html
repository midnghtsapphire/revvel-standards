About this dashboard

This app surfaces the public repository list for the Glottography organization in an accessible, keyboard-friendly layout. It supports search, language filtering, and clear summaries so the dataset is easy to browse without needing a custom application or a deep technical setup.

  • Public GitHub data is loaded from the GitHub API when available.
  • Fallback dataset support keeps the page useful if the API is slow or rate limited.
  • Color contrast, semantic structure, and visible focus states are prioritized.
