## Features

- 🤖 **20+ AI Tools** - Curated collection of the best automation tools
- 🎯 **Workflow Organization** - Tools categorized by video production stage
- 🔍 **Smart Search** - Find tools by name or description
- 📊 **Category Filtering** - Filter by scriptwriting, voiceovers, editing, etc.
- 💡 **Best Practices** - Recommended workflows and tool combinations
- 🎨 **Beautiful UI** - Modern, responsive design with dark mode

## Tech Stack

- **Framework:** Next.js 14 with App Router
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Deployment:** Vercel (static export)

## Getting Started

### Installation

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

The application runs on `http://localhost:3002` by default.
