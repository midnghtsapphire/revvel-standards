# Brand Guidelines — Master Affiliate Engine

## Brand Essence

**Master Affiliate Engine** positions as the premium, high-tech authority for creator-led affiliate automation. The visual language mirrors the WR brief: cinematic glassmorphism, neon emerald/cyan pipelines, warm gold accents, and deep space backgrounds.

## Voice & Tone

- **Authoritative** — speak as the expert who already built what others are still trying to code
- **Direct** — "Deploy in one click", not "You may be able to deploy"
- **Premium** — luxury tech aesthetic, not cheap SaaS feel
- **Empowering** — "Stop building. Start deploying."

## Color Palette

| Role | Token | Hex |
|---|---|---|
| Primary action | Emerald 400 | `#34d399` |
| Secondary accent | Cyan 400 | `#22d3ee` |
| Warm highlight | Amber 400 | `#fbbf24` |
| Deep background | Gray 950 | `#030712` |
| Glass surface | White / 5–10% opacity | — |
| Text primary | Slate 100 | `#f1f5f9` |
| Text secondary | Slate 300–400 | `#cbd5e1` |

## Typography

- **Headings:** `font-black` (900 weight), tight tracking
- **Body:** `font-sans`, `leading-relaxed`, Slate 300
- **Labels / tags:** `text-xs font-semibold uppercase tracking-widest`
- **CTA buttons:** `font-bold`, rounded-full pill shape

## Logo Usage

- Wordmark: `Master` (white) + `Affiliate` (emerald-400) + `Engine` (white)
- Always on dark background
- Minimum clear space: 16px on all sides

## UI Component Style

- **Glassmorphic cards:** `border border-white/15 bg-white/5 backdrop-blur-xl rounded-3xl`
- **Agent pipeline nodes:** Gradient borders with emerald/cyan glow, animated pulse
- **CTA button:** Gradient `from-emerald-500 to-cyan-500`, glowing `box-shadow` animation
- **Status badges:** `bg-emerald-500/15 text-emerald-300` with a dot indicator
- **Atmospheric background:** Multiple `blur-3xl` orbs with slow `fog-drift` CSS animation

## Imagery Direction

- Cinematic 9:16 vertical for TikTok/social
- Deep dark studio workspace, subtle technical components blurred in background
- Thick glassmorphic panels with refracting edges
- Neon emerald and electric cyan pipelines from a central core
- Atmospheric fog layers with cool blue and warm gold rim lighting
- Hyper-realistic 8K aesthetic, ray-traced reflections

## Do Not

- Use light backgrounds
- Use flat/pastel colors
- Use lowercase-only or all-caps branding
- Compress the glassmorphic transparency below 5% opacity
- Use serif fonts for UI elements
