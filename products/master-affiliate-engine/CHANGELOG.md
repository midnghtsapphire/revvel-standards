All notable changes to this product will be documented in this file.

## [1.0.0] — 2026-05-24

### Added

- Initial production build of Master Affiliate Engine under revvel-standards.
- Glassmorphic hero landing page with animated atmospheric fog, neon emerald/cyan pipeline map, and "Deploy This Snapshot Instantly" CTA.
- Three-node agent pipeline visualization: Automated Workflows, Smart CRM Integration, Instant Report Generator.
- Live affiliate links table showing clicks, commission, and status for five programs (Polar.sh, Vercel, Resend, OpenRouter, Stripe).
- Three-tier pricing section: Launch ($29/mo), Scale ($79/mo, Most Popular), Agency ($299/mo).
- `/dashboard` — live stats, activity feed, and pipeline metrics.
- `/admin` — admin panel with link management table and workflow controls.
- `/login` — user authentication UI (NextAuth / Supabase integration points wired).
- `/checkout` — Stripe-integrated checkout with plan selector and card form (Stripe Elements mount point).
- `README.md`, `CHANGELOG.md`, `DEPLOYMENT_GUIDE.md`, `GO_TO_MARKET.md`, `BRAND_GUIDELINES.md`, `SECURITY.md`.
- Full revvel-standards compliance: Stripe checkout surface, admin panel login, user login.
- Vercel deployment target with `vercel.json`.
- Local dev port assigned: `3006`.
