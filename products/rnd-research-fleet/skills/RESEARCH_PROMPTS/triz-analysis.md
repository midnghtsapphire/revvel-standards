# TRIZ - Theory of Inventive Problem Solving

## Overview
TRIZ is a systematic methodology for innovative problem-solving based on patterns found in patents and inventions across all engineering fields.

## Core Concepts

### Contradictions
Every inventive problem involves contradictions:
- **Technical Contradictions:** Improving one parameter worsens another
- **Physical Contradictions:** Same element needs opposite properties

### The 76 Standard Solutions

Categorized into:
1. Improving systems with no changes
2. Improving systems by changing system
3. Improving systems by pre-system changes
4. Detection and measurement
5. Simplification improvements

### S-Field Analysis
Model problems as substances (S1, S2) and fields (F):
- Insufficient interaction → Add field or substance
- Harmful interaction → Insert barrier
- Measurement problem → Add monitor substance

## TRIZ Problem-Solving Algorithm (ARIZ)

1. **Analyze Problem:** Define mini-problem, conflicting pair
2. **Analyze Problem Model:** Build S-Field model
3. **Define Ideal Result:** What solves without complications
4. **Identify Physical Contradiction:** What must be both X and not-X
5. **Apply Resources:** List available resources
6. **Use Knowledge Base:** Apply principles, standards, effects
7. **Evaluate Solution:** Check against constraints
