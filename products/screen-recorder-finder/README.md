# Mac Screen Recorder Finder

## Live Deployment

▶️ **[Open the live app & test it](https://revvel-standards.vercel.app/docs/screen-recorder-finder/)**

## Features

- 🎯 **10+ Tools Compared** - Comprehensive comparison of top Mac screen recorders
- 💰 **Budget Filtering** - Find tools within your price range
- 🔍 **Smart Filtering** - Filter by use case and required features
- ⚖️ **Detailed Comparisons** - See pros, cons, features, and pricing at a glance
- 🎨 **Interactive UI** - Modern, responsive design with dark mode
- 📊 **Feature Matrix** - Compare editing, webcam, audio, cloud, AI, and multi-clip support

### For Content Creators
- **Tella** ($13-$26/mo) - Best overall with AI features
- **Supercut** ($15/mo) - Premium 4K recording

### For Product Demos
- **Screen Studio** ($9-$29/mo) - Automatic cinematic cursor effects

### For Team Communication
- **Loom** (Free/$15/mo) - Fastest sharing and collaboration

- **Camtasia** (~$40-$600/yr) - Interactive e-learning content

- **OBS** (Free) - Advanced streaming and recording

### Beginner Friendly
- **Movavi** (~$30/mo or ~$230/yr) - Simple with scheduled recordings

## Tech Stack

- **Framework:** Next.js 14 with App Router
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Deployment:** Vercel (static export)

## Getting Started

### Installation

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

The application runs on `http://localhost:3003` by default.
