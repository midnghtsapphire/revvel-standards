# BLUEPRINT - UGC Review Generator

## Product Vision
Provide a fast, reliable tool to generate either:

1. viral UGC-style review prompts for Amazon products, optimized for AI avatar tools like HeyGen; or
2. Zeely-style local lead ads that combine overlay copy, a proof-led script, landing copy, and a 30-day publishing plan.

## Core Features
1. Custom product name input.
2. Hook selection (Unboxing vs. Problem-Solving).
3. Script formatting matching HeyGen requirements.
4. Affiliate link input.
5. Local-lead overlay generation for the screenshot-based workflow in issue `#14627`.
6. 30-day content calendar + compliance guardrails for proof/urgency claims.
