# Library — Linear A Lab sources

Per REPO_LIBRARY_STANDARD.md: one line per held item, plus licensing notes.

## Held files

- mwenge (Rob Hogan), 2019–2023, *LinearAInscriptions.js* (Linear A corpus
  data from the lineara.xyz explorer), `LinearAInscriptions.js` — carries an
  explicit public-domain dedication in its header ("The author disclaims
  copyright to this source code", SQLite-style blessing; verified
  2026-11-07). Fetched from
  <https://raw.githubusercontent.com/mwenge/lineara.xyz/master/LinearAInscriptions.js>

## Referenced, not held (and why)

- Godart, L. & Olivier, J.-P., 1976–1985, *Recueil des inscriptions en
  linéaire A* (GORILA), 5 vols, École française d'Athènes — print-only,
  copyright EFA (notably photographs/facsimiles). **Not redistributed.**
  GORILA-GE re-derives only uncopyrightable text facts.
- Salgarella, E. & Castellan, S., *SigLA — The Signs of Linear A*
  (sigla.phis.me) — reported CC BY-NC-SA 4.0 (non-commercial); **not
  ingested** to keep the lab license-clean for commercial surfaces.
- Younger, J. G., *Linear A Texts in phonetic transcription* (people.ku.edu)
  — site no longer resolves as of 2026-11-07; historical reference only.
- Douros, G., tabulation of Linear A inscriptions (spreadsheet behind the
  lineara.xyz data) — ingested only as transformed through the
  public-domain-dedicated file above.
- Unicode Standard, Linear A block U+10600–U+1077F and Aegean Numbers
  U+10100–U+1013F — character facts used in `gorila_ge/signs.py`.

## Licensing position (recorded 2026-11-07)

Sign sequences, numerals, ids, find-places and ceramic phases of Bronze Age
inscriptions are uncopyrightable facts. The one held source file is public
domain by its author's dedication. No images, drawings, or photographs from
any edition are held or redistributed. Commercial use is therefore
unencumbered; if counsel is ever needed, revisit before shipping a paid
corpus product.
