## What It Is

Graphify Evaluator provides a focused UI for teams that need to compare LLM-powered code graph extraction (Graphify) against manual and lexical-only approaches. It includes:

- A clear recommendation panel for adoption decisions
- Practical pros/cons and cost tradeoff summaries
- Built-in affiliate and newsletter modules for monetization
- Accessibility toggle for high-contrast mode

## Quick Start

```bash
cd products/graphify-evaluator
npm install
npm run dev -- -p 3007
```
