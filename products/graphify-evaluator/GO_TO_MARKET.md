# Go-to-Market — Graphify Evaluator

## Market Positioning

Graphify Evaluator is positioned for engineering teams that need fast architecture visibility in large repositories without relying only on manual diagrams.

## Product Definition (From Research)

- **Product being built:** Graphify Evaluator
- **Delivery shape:** Production web application in `products/graphify-evaluator`
- **What it does:** Helps teams evaluate Graphify-powered semantic code graphing against manual/lexical alternatives before adopting in delivery workflows.

## Pricing Strategy

| Tier | Price | Value |
| ---- | ----- | ----- |
| Free | $0 | Public evaluator and recommendation framework |
| Pro | $29/mo | Saved evaluations, shared reports, expanded comparison templates |
| Team | $99/mo | Team workspaces, decision history, export and review workflows |

## Distribution Plan

1. Publish technical walkthrough content around code graph evaluation workflows.
2. Cross-promote through developer communities and architecture-focused newsletters.
3. Use affiliate relationships tied to model providers and hosting platforms already referenced in the product UI.

## Revenue Path

- SaaS subscriptions (Pro and Team)
- Affiliate commissions from recommended infrastructure/tools
- Sponsored placements for relevant developer tools (clearly disclosed)
