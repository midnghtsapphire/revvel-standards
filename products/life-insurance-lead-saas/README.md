# Life Wizard - Insurance Lead SaaS

This is the production app for the Life Wizard insurance lead generation landing page. It is built as a Next.js 15 app with Tailwind CSS.

## Features
- Next.js 15 with App Router
- Tailwind CSS
- Accessibility Controls (Contrast and Text Size)
- Affiliate Module
- Newsletter Module

## EXRUP Artifacts
- BLUEPRINT.md
- ROADMAP.md
- KANBAN_CARDS.md
- INVESTORS_PACK.md
- CHANGELOG.md

## Development
To run in development: \`cd build && npm run dev\`

## Production
To build and run in production: \`cd build && npm run build && npm start\`
