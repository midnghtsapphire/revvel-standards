# BLUEPRINT - Life Wizard Insurance Lead SaaS

## Overview
This is a landing page built to generate insurance leads. It sells exclusive outbound leads and live transfers for ACA, Life, Health, and Medicare agents.

## Architecture
- Frontend: Next.js 15
- Styling: Tailwind CSS
- Deployment: Vercel (recommended)

## Key Components
- Home Page (features, pricing, how it works)
- Accessibility Module
- Affiliate Marketing Module
- Newsletter Module
