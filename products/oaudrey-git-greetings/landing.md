# Add That Extra Umph to Your GitHub Repositories

First impressions matter. When a developer takes the time to contribute to your project, how are they greeted? With silence? With a wall of automated linter failures?

**oAudrey Git Greetings** changes that.

This lightweight, zero-dependency GitHub Action brings immediate, personalized interaction to your repository. It automatically detects new issues and pull requests and posts a welcoming comment that adds that much-needed "extra umph" to your community building.

## Why oAudrey Git Greetings?

- **Personalized Touch:** Detects if it's a contributor's very first time interacting with your repo and tailors the welcome message accordingly to celebrate the milestone.
- **Instant Gratification:** Provides immediate feedback and acknowledgement, keeping contributors engaged.
- **Customizable:** Easily append your own team's specific guidelines, culture, or important links (like `CONTRIBUTING.md`) to the automated greeting.
- **Zero External Dependencies:** Built with security in mind. Uses native Node.js libraries to interact with the GitHub API directly.

Bring your repositories to life today with oAudrey Git Greetings!
