---

## Quick Start

```bash
# Run UI creation engine
npm run ui-engine -- \
  --business="Business Name" \
  --industry="industry type" \
  --location="City, State" \
  --output="./output-dir"

# Example: Catering business
npm run ui-engine -- \
  --business="Soul2Bowl" \
  --industry="catering, meal prep" \
  --location="St. Louis, MO" \
  --output="./soul2bowl-ui"
```

---

## What This Does

Creates cutting-edge website and mobile app interfaces that compete with top vendors in the USA.

### Features

- **Competitive Research**: Analyze top 10+ competitors using OpenRouter swarms
- **Image Optimization**: Generate SEO filenames, alt text, WebP conversion
- **SEO Metadata**: Comprehensive metadata achieving Lighthouse scores 95+
- **UI/UX Excellence**: Design patterns matching industry leaders
- **Differentiation Strategy**: Identify unique angles and competitive advantages
