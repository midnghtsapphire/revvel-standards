# Polar.sh GitHub Funding Strategy

## Prime Directive
$10k/month → $10M in 3 years via automated OSINT product pipeline + Polar.sh funding.

## Phase Roadmap
| Phase | Timeline | MRR Target | Focus |
|-------|----------|-----------|-------|
| 1 | Month 1-6 | $10k/mo | Polar.sh setup, OSINT MVP, first sponsors |
| 2 | Month 6-18 | $30k/mo | Tiered sponsorships, product launches |
| 3 | Month 18-30 | $100k/mo | Enterprise tier, SaaS conversion |
| 4 | Month 30-36 | $10M total | Scale, acquisition-ready |

## Polar.sh Setup Checklist
- [ ] Connect GitHub org to https://polar.sh
- [ ] Enable donations on public repos
- [ ] Configure `.github/FUNDING.yml` with `polar: <org>`
- [ ] Create tiered subscription products ($5/$25/$100/$500/mo)
- [ ] Add "Sponsor" CTA to top of every README
- [ ] Publish first paid post to activate the flywheel

## OSINT Product Pipeline
1. Free CLI scanner → GitHub stars → Polar sponsors
2. Hosted dashboard → $25/mo tier
3. API access → $100/mo tier
4. Enterprise SLA → $500-5000/mo tier
