# TikTok Affiliate Engine - Research Brief

## The Problem
Dropping raw affiliate links in a TikTok bio results in extremely low conversion rates. Viewers have high friction and low trust to click a random link to buy software.

## The Solution
The "Copy My System" strategy. Instead of selling a product, creators sell a *result* by offering a free blueprint, guide, or snapshot. The user opts in for the free asset, and the backend automated system (this engine) delivers the asset while simultaneously introducing the affiliate links required to "clone" the setup.

## Visual Strategy
A core component of TikTok virality is aesthetic coherence. If a hook says "making passive income at night", the landing page must maintain that dark-mode, sapphire/charcoal vibe so the user doesn't bounce. If it's a high-energy morning hook, the page needs to be bright and amber-toned.
