# TikTok Affiliate Engine

A "Copy My System" Lead Magnet funnels generator engineered for TikTok virality and passive affiliate income.

## Overview

Instead of putting a low-converting raw affiliate link in a TikTok bio, this engine provides a **high-value lead magnet funnel**. The creator posts a "Copy My System" video, drives viewers to this optimized landing page to get a free asset (like a template or guide), and the system automatically follows up with the backend affiliate links (like Twilio, Cal.com, etc.).

It features aesthetic matching (light/dark mode) so the landing page matches the visual hook of the TikTok video.
