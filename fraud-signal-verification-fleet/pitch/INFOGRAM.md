# Infogram spec (data-viz brief)

## Panel 1 — Funnel
Source → Decompose → 5 agents (fan-out) → Score → Judge → Ledger.
Visual: left-to-right funnel; the red-team agent in a contrasting color.

## Panel 2 — Double cap (the hero graphic)
Two horizontal ceiling bars over a confidence bar:
- Tier cap (source quality)
- Stage ceiling (legal standing)
Show a claim pushing up and being stopped by the LOWER of the two.
Caption: "Confidence is capped twice. Loud ≠ proven."

## Panel 3 — Tier ladder
5→1 with weights (1.00→0.15) and one example each.

## Panel 4 — Provenance dial
filing 1.00 … anonymous_report 0.25. Needle on "how did they get it?".

## Panel 5 — Band legend
SUBSTANTIATED / SUPPORTED / WEAK / UNSUBSTANTIATED / REFUSED, with the color
chips used in the dashboard (greens / amber / grey / red-lockout).
