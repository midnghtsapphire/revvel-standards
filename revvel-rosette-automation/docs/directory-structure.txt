Key Paths
---------

Configuration:
  • Main config: config/59-config.yaml
  • Project registry: config/300Projects.yaml
  • Agent factory: config/61-factory.yaml

Executables:
  • Orchestrator: python3 src/orchestrator.py
  • Scheduler: python3 src/scheduler.py
  • Gatekeeper: python3 src/gatekeeper.py
  • Self-healer: python3 src/selfheal.py

Scripts:
  • Setup: ./scripts/bootstrap.sh
  • Test: npm test OR ./scripts/manual-test.sh
  • Monitor: ./scripts/monitoring.sh
  • Daily run: ./scripts/cronjob.sh

Queue:
  • Main queue: queue.txt
  • Failed tasks: dlq.txt

Logs:
  • Daily logs: logs/cronjob-YYYYMMDD.log
  • Factory logs: logs/factory.log
  • Last run: logs/last-run.txt

Runtime Directories
-------------------

These directories are created automatically at runtime:

logs/     - Log files from all automation runs
data/     - Application data (databases, caches)
backups/  - Automated backups
queue/    - Task queue files (if using file-based queue)

Configuration Hierarchy
-----------------------

1. Environment variables (highest priority)
   - DOPPLER_TOKEN, GITHUB_TOKEN, etc.

2. config/59-config.yaml (main config)
   - References other config files
   - Contains most runtime settings

3. config/20-supportingconfig.yaml (services)
   - Email, Slack, DigitalOcean, etc.

4. config/61-factory.yaml (agent factory)
   - Agent definitions and OpenRouter settings

5. config/70-vaultwardent.yaml (vault)
   - Vault integration settings

6. config/300Projects.yaml (projects)
   - Project registry (read by orchestrator)

Development Workflow
--------------------

1. Bootstrap:
   ./scripts/bootstrap.sh

2. Configure:
   Edit config/59-config.yaml
   Set environment variables

3. Test:
   npm test
   ./scripts/manual-test.sh

4. Run:
   python3 src/orchestrator.py --run-all

5. Monitor:
   ./scripts/monitoring.sh
   tail -f logs/cronjob-*.log

6. Deploy:
   Set up cron job:
   0 3 * * * /path/to/revvel-rosette-automation/scripts/cronjob.sh
