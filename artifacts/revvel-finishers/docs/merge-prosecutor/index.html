Merge Prosecutor

Deterministic gate. Levenshtein distance on consecutive added lines, conflict markers, dismissive phrasing, unimplemented fenced suggestions. No model call.

This page runs the checks in your browser. It does not open a GitHub issue. The Action in products/merge-prosecutor does: a failed pull request files a [WR] issue, which is the Work Request the call chain starts from. A markdown file written on the Actions runner is discarded when the job ends.
